HiLo-WAM: Decoupling Long-Horizon Task Evolution and Local Dynamics in World Action Models

한 WAM이 모든 미래 프레임을 빽빽하게 생성하는 대신 장기 작업 진척과 근거리 접촉 동역학을 다른 시간 해상도로 예측하는 HiLo-WAM. dual-DiT, 비대칭 attention, 점진적 denoising을 실험표와 로봇 평가를 통해 검토한다.

00 / ONE-MINUTE RECAP

핵심을 먼저 읽기

‘무슨 단계까지 왔는가’를 기억할 희소 장기 프레임과 ‘지금 손끝에서 무슨 일이 일어나는가’를 예측할 조밀한 단기 프레임을 분리하되, action generation은 두 정보에 접근한다. 최종 로봇 행동을 생성할 때 고불확실성의 먼 미래 프레임을 직접 참고하지 않도록 attention을 제한하는 것이 핵심이다(§3).

⌁ DEEP TECHNICAL REVIEW연구자용 상세 해설

왜 두 시간 척도인가? HiLo-WAM은 'future video를 얼마나 길게 뽑나'보다 '긴 미래의 불확실성이 정밀 제어를 망치지 않으면서 어떤 문맥을 제공할 수 있나'를 묻는다. §3의 asymmetric attention, §4의 ablation/temporal stride, Appendix A의 정확한 8·8·4 설정을 기준으로 읽는다. 시뮬레이션 성적과 실제 GR-3의 결과는 반드시 분리한다.

01 / 문제 정의

연구가 풀려는 문제

길고 복합적인 조작에서 로봇이 병을 계속 같은 상자에 넣어야 하는 상황을 떠올리면, 바로 앞 1초의 그리퍼 접촉만 봐서는 앞서 어떤 병을 선택했는지 잃을 수 있다. 반면 모든 장기 과정을 고프레임레이트로 생성하면 계산이 커지고 멀리 있는 미래 예측 오차가 행동을 오염시킨다. 기존 단일 시간 척도 WAM은 접촉 정밀도와 작업 전체의 순서를 동시에 만족시키기 어렵다. HiLo-WAM은 별도의 언어 플래너를 두는 대신 시각적 미래 예측 자체를 두 시간 해상도로 분리한다(§1–2).

02 / 핵심 기여

핵심 아이디어

long-horizon stream은 과거 키프레임 8개와 희소 미래 프레임 8개를 stride k=4로 처리해 진척·목표 지속성을 포착한다. local stream은 32 프레임 규모의 근거리 시각 변화를 조밀하게 다룬다. Action DiT는 두 visual stream의 요약을 받아 연속 행동 chunk를 생성한다. 비유하자면 장기 stream은 ‘요리 전체 레시피의 단계 카드’, local stream은 ‘지금 칼끝과 재료의 순간 영상’이다. 서로 연결되지만 두 가지 해상도에 같은 계산을 할당하지 않는다(§3.2–3.3, Figure 2).

DEEP DIVE / 04

기존 연구와 무엇이 다른가?

Fast-WAM은 단기/local video 세계 모델과 행동 생성으로 강한 기준선을 제공하고, AHA-WAM은 장기 시각 문맥을 다루는 대조군이다. HiLo-WAM의 핵심은 장기 정보를 단순 추가하는 것보다 그 정보가 어떤 시점의 action에 접근할 수 있는지 제어한 비대칭 attention과 stream별 denoising 예산이다. π0.5와 같은 VLA가 명시적 소과제 언어를 생성하는 방식과 달리, 여기는 시각 세계 모델의 시간 해상도를 나눈다.

03 / 설계와 학습

방법론 · 아키텍처

Wan2.2-5B 계열 비디오 VAE/Video DiT와 별도 Action DiT, T5 언어 인코더를 사용한다. 고해상도 시간축 로컬 비디오와 다운샘플된 장기 비디오를 동일 VAE로 별도 인코딩해 H/L 시각 토큰, 현재 상태 q, action 토큰 네 그룹을 구성한다. 비대칭 attention은 long-horizon 전 구간 내부 교환을 허용하지만, 로컬/행동 분기는 장기 과거와 가까운 미래에만 접근하고 먼 미래는 직접 읽지 않는다. 세 stream의 Flow Matching loss를 함께 최적화하며 λH=λL=λA=1을 사용한다. 추론은 action 10 step을 유지하면서 H/L은 각각 5 step에서 멈춰 cache, joint denoising와 유사 velocity의 dynamic skipping으로 비용을 낮춘다(§3, Appendix A).

DEEP DIVE / 01

모델 구조와 처리 흐름

개념적 처리 순서를 정리한 편집 다이어그램이며 원논문의 그림을 복제한 것은 아닙니다.

  1. 01

    1. 로봇 현재 관측 및 언어 목표

    각 t에서 RGB 이미지 oₜ, 14차원 로봇 상태 sₜ, 언어 지시 ℓ가 들어오며 14D action chunk를 예측한다. 개념적으로 필요한 관측은 작업 진행 과거와 손끝 상호작용 현재지만 두 정보를 동일 빈도로 샘플링할 필요는 없다.

    (oₜ,sₜ,ℓ) → 두 시간 척도의 visual context
  2. 02

    2. 고수준 장기 시각 stream을 희소 샘플링

    과거 m=8, 미래 n=8 키프레임을 stride k=4로 뽑는다. 장기 stream은 물체가 어느 단계까지 놓였는지, 목표가 앞으로 어떻게 변해야 하는지에 관한 coarse visual progression을 모델링한다. 생성 미래가 정확한 픽셀 정답이라는 가정이 아니다.

    H stream: {oₜ₊ᵢₖ}, i=−8…8; k=4
  3. 03

    3. 국소 시각 stream은 근거리 변화에 집중

    현재와 가까운 32프레임을 밀도 높게 생성하도록 local stream을 만든다. 컵 손잡이 정렬, 블록 모서리 접촉처럼 작은 자세 변화가 중요하다. 두 비디오 시퀀스는 공통 pretrained VAE로 각각 인코딩한다.

    L stream: dense VAE latents, T=32
  4. 04

    4. 공유 Video DiT와 별도 Action DiT

    Wan2.2-TI2V-5B로 초기화한 30-layer Video DiT가 두 시각 stream을, 30-layer Action DiT가 state/action token을 처리한다. 영상·행동은 modality별 파라미터를 유지하고 층별 joint attention으로 교환한다. T5가 양쪽에 언어 조건을 제공한다.

    [Z_H, Z_L, q, Z_A] → structured MoT
  5. 05

    5. 비대칭 attention + 세 개의 flow loss

    H 내부는 상호 참조하지만 L과 A가 직접 읽는 장기 정보는 historical context 및 가까운 미래(H_near)뿐이다; H_far는 고불확실성으로부터 action을 보호하기 위해 직접 차단한다. H/L/A의 미래 및 action latent에 독립적으로 flow time을 샘플링하고 동일 가중치 1의 loss를 합한다.

    L= L_H + L_L + L_A; far-future direct access 차단
  6. 06

    6. Progressive inference로 video 계산 멈추기

    10회 denoising하는 action stream을 끝까지 실행하면서 H/L은 각각 5회만 계산 후 feature를 cache한다. 처음에는 동시 denoising, 후반에는 cached visual를 action이 재사용한다. 비슷한 velocity가 반복되는 단계는 cosine similarity 임계값에 따라 DiT eval을 건너뛴다.

    n_H=5, n_L=5, n_A=10; partial→joint→skipping
  7. 07

    7. 두 종류의 시뮬레이션과 하나의 실물 설정에서 점검

    RoboTwin 50 tasks는 각 clean/randomized 50 trials, RoboDojo 8 long tasks는 각 50 trials, 실물 GR-3는 Build/Disassemble House·Disassemble Heart 세 과제 각각 10 trials이다. progress와 strict success, 실물의 OOD 교란 범위를 분리해 기록한다.

    simulation vs real, completion vs progress

05 / 비판적 해석

한계와 비판적 검토

기반 비디오 모델이 잘못 이해하는 복잡한 계획·명시적 소과제 분해는 이 구조만으로 해결하지 못한다(§5). RoboTwin의 높은 숫자는 광범위한 현실 성공률을 뜻하지 않으며 RoboDojo에서 strict success는 6.5%로 여전히 낮다. 실물 실험도 한 종류의 Fourier GR-3와 세 작업, 조건당 10회의 작은 표본이다. 도메인 랜덤화는 명시된 시각/물리 교란일 뿐 임의 현장 전체를 포함하지 않는다. 단일 GPU에서 측정한 추론 지연과 실제 제어 시스템 end-to-end latency 역시 구분해야 한다.

RESEARCH LAB / EDITORIAL PROPOSAL

내 연구에 적용한다면?

아래는 논문 저자의 검증 결과가 아니라, 논문에서 출발해 설계한 **후속 실험 제안**입니다.

검증 가설

과거 장기 목표 지속성과 근거리 접촉 정보를 분리하되 H_far의 직접 attention을 차단하면 장기 시퀀스에서 목표 전환 오류와 정밀 조작 오류를 동시에 줄인다.

구체적 실험 설계

RoboTwin 2.0의 동일 50 tasks/동일 50+500 demos 프로토콜로 H_ctx/H_near/H_far mask, local-only, k=1/4/8을 통제하고 GPU별 latency를 기록한다. 가능하면 실물 GR-3 외의 platform에서 10회보다 더 많은 episode를 실행한다.

비교군·Ablation

Fast-WAM, long-only, local-only, full mask, H_far unmasked, n_H/n_L 5/10 steps

기록할 지표

task strict success per task, milestone progress, target-switch rate, contact alignment error, rollout length, action-chunk wall time, 실패후 복구

실패 해석·주의점

사용된 pretrained video backbone·데이터 mixture 차이, 물리 실험의 장비 안전과 소표본, long context에서 episode leakage를 통제해야 한다.

World Action Model을 두 시간 축의 시각 생성으로 나누어 조작 성능·처리 지연을 함께 개선하려는 연구. 제시한 성공률은 각기 다른 시뮬레이션/실물 테스트를 혼합한 수치가 아닌 원문별 조건을 따로 기록한다.
