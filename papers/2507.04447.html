01 / 문제 정의

연구가 풀려는 문제

일반적인 VLA는 현재 영상과 언어를 행동으로 직접 사상한다. 미래 영상 전체를 생성하는 대안은 배경처럼 행동에 무관한 부분까지 복원해야 하고 단안 RGB의 공간·객체 의미를 명시적으로 감독하지 않는다. DreamVLA는 움직일 부분, 깊이 관계, 물체 특징을 미래의 중간 목표로 학습한다. 이는 후보 행동을 입력해 여러 미래를 rollout하는 고전적인 action-conditioned dynamics 모델과 구별되는 미래 표현 기반 VLA다.

02 / 핵심 기여

핵심 아이디어

서랍을 열라는 지시에서 책상 전체의 미래 색상을 정확히 그리는 것보다 손잡이와 서랍 앞판의 움직임, 로봇과 서랍 간의 상대 깊이, 서랍이라는 객체의 특징이 중요하다. 모델은 세 종류의 질문 토큰으로 이 정보를 예측하고 별도의 행동 질문이 그 잠재 표현을 읽는다. 실제 제어 시에는 미래 depth map을 화면에 그린 후 다시 읽는 것이 아니라 내부 표현을 바로 활용한다. 따라서 보조 감독과 실제 실행 경로를 구분해야 한다.

DEEP DIVE / 04

기존 연구와 무엇이 다른가?

OpenVLA는 직접 행동, Susie는 두 단계 미래 목표와 inverse dynamics, GR-1은 영상 예측을 활용한다. DreamVLA는 미래 다중 표현을 학습 시 감독하지만 추론에서 decoder를 제외하는 구조다. CALVIN 표의 기존 비교군은 서로 다른 사전학습 데이터 및 backbone을 사용하므로 방법론 한 가지의 인과 효과는 Table 4–7의 내부 비교를 중심으로 판단한다.

03 / 설계와 학습

방법론 · 아키텍처

01. 멀티모달 입력: 현재/과거 영상·언어·proprioception을 인코딩한다. Figure 2의 텍스트/시각 encoder는 동결, 상태 encoder는 학습된다. Appendix A의 GPT-2 Medium backbone은 24층, hidden 1024, 약 345M이다. 02. Dream query: 학습 가능한 modality별 query를 멀티모달 토큰과 결합해 공유 언어모델에서 미래 잠재 표현을 만든다. 본문 §4.1의 modality별 query 길이는 9다. 03. 동적 영역과 depth 감독: CoTracker로 움직이는 영역을 추출해 해당 픽셀만 복원하도록 감독한다. Depth-Anything 또는 깊이 GT를 사용하며 scale-normalized MSE로 전역 스케일 모호성을 줄인다. 04. 의미 감독 및 attention: DINOv2와 SAM의 미래 특징을 InfoNCE로 학습한다. 공간적으로 이동한 특징을 negative로 사용한다. modality subquery 사이 직접 attention을 차단하고 과거 문맥으로 causal 제한한다. 05. 행동 diffusion 학습: 별도 action query가 잠재 행동을 집계한다. DiT는 이 조건에서 노이즈를 예측하여 행동 시퀀스를 복원한다. 본문 손실 가중치는 dyn 0.1, depth 0.001, sem 0.1, action 1이다. 06. 추론: 학습 전용 world decoder들을 실행하지 않고 latent world/action embedding을 행동 DiT에 제공한다. 본문 DiT 10 diffusion steps. 새 관측으로 과정을 반복한다. 물리적 충돌 안전이 구조적으로 보장되는 것은 아니다.

  3. 03

    03. 동적 영역과 depth 감독

    CoTracker로 움직이는 영역을 추출해 해당 픽셀만 복원하도록 감독한다. Depth-Anything 또는 깊이 GT를 사용하며 scale-normalized MSE로 전역 스케일 모호성을 줄인다.

    future region/depth targets
  4. 04

    04. 의미 감독 및 attention

    DINOv2와 SAM의 미래 특징을 InfoNCE로 학습한다. 공간적으로 이동한 특징을 negative로 사용한다. modality subquery 사이 직접 attention을 차단하고 과거 문맥으로 causal 제한한다.

    structured mask + semantic targets
  5. 05

    05. 행동 diffusion 학습

    별도 action query가 잠재 행동을 집계한다. DiT는 이 조건에서 노이즈를 예측하여 행동 시퀀스를 복원한다. 본문 손실 가중치는 dyn 0.1, depth 0.001, sem 0.1, action 1이다.

    conditional noise loss + auxiliary losses
  6. 06

    06. 추론

    학습 전용 world decoder들을 실행하지 않고 latent world/action embedding을 행동 DiT에 제공한다. 본문 DiT 10 diffusion steps. 새 관측으로 과정을 반복한다. 물리적 충돌 안전이 구조적으로 보장되는 것은 아니다.

    latent → action chunk → observation
