Coordinating Humanoid Loco-Manipulation through Action-Conditioned Latent Foresight

Unitree G1 휴머노이드가 생성한 몸통·손 액션 후보 8개를 실행 전에 미래 시각 진척과 시간 일관성으로 평가하는 latent WAM. SIMPLE 10과제 89.7%, 실물 7과제 표준 85.7%·미지 배치 65.7%의 조건과 실패를 분석합니다.

01 / 문제 정의

연구가 풀려는 문제

로봇이 바구니를 들어 식탁 위에 올릴 때 팔을 치켜드는 모션 자체가 그럴듯해도 그립이 풀리면 바구니가 떨어집니다. 세탁물을 드럼 안에 넣을 때도 문을 열고 셔츠를 옮기는 일련의 동작이 동시에 맞아야 합니다. 영상에서 좋은 마지막 장면만 예측해도 중간 접촉이 불안정할 수 있고, 관절 변화량을 부드럽게 만드는 것만으로 목적 작업이 완성되지도 않습니다. 이 논문은 단순 VLA 생성기 위에 사전 검증기를 두어, 후보 명령 시퀀스가 진짜 목표에 접근하면서 운동·손동작이 연결되는지를 계산합니다. (§I–III)

02 / 핵심 기여

핵심 아이디어

행동 생성기는 Qwen3-VL 기반 관측/언어 경로와 action DiT로 여러 body+hand command chunk를 제안합니다. 동결된 V-JEPA 2.1 feature space의 action-conditioned endpoint predictor가 각 후보 h-step 후의 시각 특징을 예측하고 시연에서 추출한 현재 subgoal과의 거리가 얼마나 줄어드는지 V_i를 계산합니다. 별도 2층 GRU joint temporal prior는 몸통·손 명령의 시계열 이탈 정도 E_i를 평가합니다. 합성 점수 V_i−βE_i가 최대인 후보를 택하고 K개 명령만 실행 후 다시 관측합니다. Figure 1은 실패/성공 사례와 score 개념, Figure 2는 훈련·추론 파이프라인입니다. (§III, Fig.1–2)

DEEP DIVE / 04

기존 연구와 무엇이 다른가?

직접 VLA 실행/예측 미래를 action 생성 조건에 넣는 방식 대신 이 모델은 N개 후보를 실제 실행 전에 점수화하고, 그중 첫 K개 명령만 집행하는 모델예측제어와 유사한 선택 과정을 둡니다. 시각 진척 단독보다 joint temporal prior가 특정 설정에서 유리하지만, 성공 시연 subgoal과 계산 예산을 요구합니다.

03 / 설계와 학습

방법론 · 아키텍처

Unitree G1에서 시각 o_t, 언어 ℓ, 고유수용 상태 s_t로 N=8개 명령 chunk A∈R^{H×d_a}를 생성합니다. 실물 H=40, 시뮬 H=30, 평가 h=20, 실행 K=10, 30Hz로 설정합니다(Table I). 인코더 V-JEPA 2.1은 현재 및 예상 미래에서 특징을 뽑고, endpoint predictor는 로봇 상태와 후보 prefix를 조건으로 h-step 도착 특징을 예측합니다. 데모에서 추출한 시간 순서 subgoal 다섯 개 중 현재 목표를 선택합니다. predicted endpoint까지의 cosine distance 감소가 시각 진척이고, joint GRU prior가 body/hand 양측 history를 함께 보고 시간적 부조화 페널티를 냅니다. 학습에서는 demonstration prefix와 실제·예측 feature 변화에서 첫 command를 복원하는 action-consistency regularization(ACR)을 추가합니다. 이 복원 신호는 world predictor에 action 정보를 남기게 합니다. (§III, Table I)

DEEP DIVE / 01

모델 구조와 처리 흐름

개념적 처리 순서를 정리한 편집 다이어그램이며 원논문의 그림을 복제한 것은 아닙니다.

  1. 01

    01 · 후보 행동 시퀀스 생성

    현재 1인칭 RGB, 언어 명령, 관절/몸 상태를 Qwen3-VL과 action DiT에 입력하여 몸통과 손의 명령 chunk를 N=8개 샘플링합니다. 각 candidate는 ‘전체 동작’이 아닌 h-step prefix로 평가됩니다.

    o_t, ℓ, s_t → {A_t^(1)…A_t^(8)}
  2. 02

    02 · 성공 시연에서 visual subgoal 선택

    동결된 V-JEPA 2.1의 시각 특징 변화 누적량을 이용해 데모의 subgoal 이미지 다섯 개를 시간 순서대로 추출합니다. 현재 활성 목표를 기준으로 시각 거리 감소를 계산합니다.

    ordered G=(g1,…,g5) → active g_t
  3. 03

    03 · action-conditioned endpoint foresight

    각 후보의 평가 prefix B=A[0:h]를 현재 시각 특징·상태와 함께 예측기에 넣어 h 이후 endpoint의 V-JEPA feature를 추론합니다. 미래 실제 영상 관측이 아니라 예상 latent이므로 예측 오류를 감안해야 합니다.

    B, s_t, z_t → ẑ_(t+h)
  4. 04

    04 · 시간 prior와 합성 스코어

    GRU joint prior는 몸통과 손이 함께 이어지는 명령 연쇄를 평가합니다. 예측한 시각 진척 V_i에서 βE_i를 빼 최대 후보를 선택합니다. β=0.1, 평가 h=20, GRU 2층·512 hidden을 Table I에서 확인할 수 있습니다.

    i* = argmax_i(V_i − β E_i)
  5. 05

    05 · 짧게 실행하고 다시 계획

    선택한 시퀀스의 첫 K=10개 명령만 30Hz로 실행한 뒤 새 RGB/robot state를 관측해 후보 생성과 평가를 반복합니다. 모델이 시뮬·실물에서 다른 H를 사용하며 p95 지연은 추론 하드웨어에 민감합니다.

    execute A_i*[0:10] → reobserve → replan
DEEP DIVE / 02

핵심 설계·학습 신호 해설

시각 진척: 목표까지 거리가 얼마나 줄었나

현재 feature z_t와 목표 z_g의 cosine distance에서 후보 endpoint의 예측 feature ẑ와 z_g의 거리를 뺀 값이 V입니다. 사진상 바구니가 목표 방향으로 이동했는지의 proxy이지 실제 파지력이나 충돌 여부를 직접 계산하지 않습니다. (§III-A Eq.2)

읽기 포인트단순 proximity와 올바른 접촉/타이밍을 혼동하지 마십시오.

Joint temporal prior: 몸통과 손의 연속성

2층 GRU가 body-motion 및 hand-control의 joint history를 함께 참조하여 다음 명령 예측 오차 에너지를 계산합니다. 고정 smoothness penalty나 각 그룹을 따로 예측하는 factorized prior보다 특정 4개 과제에서 높은 성공률을 보였습니다. (§III-D, Table VII)

읽기 포인트joint prior 효과의 9.2 pp는 같은 네 과제 subset의 결과입니다.

ACR: 행동 변화를 잠재 모델에 남기기

현재와 미래의 V-JEPA feature 차이 및 예측 feature 차이로 demonstration의 첫 command를 다시 복원하는 보조 손실입니다. 이미지 latent이 조작에 무관한 시각 변화만 학습하는 문제를 완화하려 합니다. ACR 유무 실험은 55.0% vs 65.8%입니다. (§III-E, Table VI)

읽기 포인트보조 손실을 추가해 분량이 늘어나는 효과와 메커니즘 효과는 구분해야 합니다.

실물과 온보드 시스템의 분리

Table I의 정책 평가 RTX 4090D(48GB)와 onboard Jetson Orin NX(16GB)는 다른 환경입니다. RTX 4090D에서는 9.1 command chunks/s, Jetson에선 0.73Hz로 실시간 배포 병목이 생깁니다. (§IV-G)

읽기 포인트‘9.1Hz’와 30Hz control command rate는 같은 측정량이 아닙니다.

05 / 비판적 해석

한계와 비판적 검토

SIMPLE은 10개 지정된 과제의 시뮬레이션이고 실물 7과제 역시 과제당 별도 정책을 학습합니다. 오픈월드 범용 모델이 아닙니다. 시각 subgoal은 성공 데모에서 추출한 이미지 다섯 장에 의존하며, 완전히 새로운 작업의 goal 이미지를 어떻게 얻는지는 해결되지 않았습니다. 표준 대비 unseen-object 설정은 실험 Appendix A에 지정된 물체·배치·색상 변형이지 새로운 모든 환경이 아닙니다. 실제 실패에는 수도꼭지를 끝까지 못 돌림, 페달식 쓰레기통 뚜껑 미개방, 장난감 파지 실패가 남았습니다. Jetson onboard 추론 0.73Hz는 4090D의 9.1Hz와 큰 차이가 있어 실시간 제약을 논해야 합니다. (§IV-E,G, Appendix A–B)

07 / ABSTRACT & PROVENANCE

원문 / 출처 확인

편집자가 작성한 초록 기반 한국어 요약이며 공식 영문 초록의 원문/번역이 아닙니다.

Humanoid loco-manipulation requires coordinated body motion and hand interaction over time, and a plausible-looking command sequence can still drop a held object or leave an interaction incomplete. We present action-conditioned latent foresight, a latent world-action model (WAM) that evaluates proposed command sequences before execution. An action generator proposes joint motion-hand command sequences from vision, language, and the robot state. An action-conditioned endpoint predictor estimates the visual features each sequence prefix reaches and measures progress toward a demonstration-derived subgoal, while a joint temporal prior scores temporal consistency given the robot state and preceding commands. The robot executes the first commands of the best-scoring sequence and replans from the next observation. During training, action consistency regularization reconstructs the first demonstrated command from observed and predicted feature changes, encouraging the predictor to retain action-relevant information. On ten tasks in the humanoid loco-manipulation simulation benchmark SIMPLE, our method achieves 89.7% average success, compared with 73.7% for Psi-Zero and 82.0% for DiT4DiT. On seven real-robot tasks, it achieves 85.7% under standard conditions and 65.7% under unseen object configurations, while GR00T N1.7 achieves 70.0% and 48.6%, respectively.
