PGX: Physically Grounded Execution for Long-Horizon Humanoid Loco-Manipulation

PGX는 VLA를 새로 대형화하지 않고 물리 predicate 상태기계·world-coordinate locking으로 휴머노이드 장기 과제를 실행한다. Unitree G1·π0.5·GR00T 비교, nominal/random start success, station drift, real G1 조건을 Figure1·2, Table I–III로 검증.

00 / ONE-MINUTE RECAP

핵심을 먼저 읽기

PGX의 중요한 발견은 VLA가 모든 작업 순서를 암기하지 않아도 된다는 것이다. 언제 끝났는지(state predicate)와 어디서 동작할지(world frame)를 executor가 관리하면 같은 GR00T 가중치로 커피 과제 nominal success 35→80%를 얻는다(§III–IV).

⌁ DEEP TECHNICAL REVIEW연구자용 상세 해설

01 / 문제 정의

연구가 풀려는 문제

휴머노이드에게 ‘커피를 가져와’라고 지시하면 걷기, 머그 집기, 머신 앞 정렬, 놓기, 버튼 누르기, 기다리기, 다시 잡기, 전달하기가 뒤섞인다. flat VLA는 학습 데이터에서 긴 걷기와 대기 구간 비중이 커서 손동작 표현이 약해질 수 있고, 머그를 집었다는 착각으로 머신 동작을 건너뛰기도 한다. 이동하는 골반 좌표계를 기준으로 손을 제어하면 버튼 접촉 위치가 서서히 흔들린다. 기존 전통 제어는 각 기술을 수작업 제작해 정밀하나 복잡한 접촉을 학습하기 어렵다. PGX는 VLA는 손 조작에 집중시키고 물리적 전제·기하 제약은 외부에서 처리한다.

02 / 핵심 기여

핵심 아이디어

Task를 stage graph로 표현하고 stage마다 (언어 명령, executor, 완료 판정, 타임아웃, 회복정책)를 고정한다. `grasped`는 그리퍼 닫힘만 보지 않고 손목-물체 거리와 물체 높이 변화를 함께 검사한다. `placed`, `triggered`, `at-stance`, `dropped` 등 guard가 전이를 결정하고 실패 시 retry 또는 이전 단계로 복귀한다. WCL(world-coordinate locking)은 목표 물체에 상대적인 도착 자세·작업대 기준 base station keeping·버튼 world-anchored contact target을 관리한다. Fig.1은 flat VLA와 PGX의 실제 실패 유형, Fig.2는 FSM–VLA–WCL의 권한 분할을 보여준다. 이 기술은 새로운 network architecture가 아니라 학습 없이 붙이는 실행 구조다.

DEEP DIVE / 04

기존 연구와 무엇이 다른가?

대형 VLA 성능 개량 연구와 달리 PGX는 이미 학습한 π0.5, GR00T N1.6 위에 물리 제약을 입히는 hybrid executor다. 기존 behavior trees/FSM과 새로운 AI를 배타적 대안으로 두지 않고 접촉-rich 조작만 VLA에 맡긴다. 다만 수동 predicate, Vicon, stage graph 준비비용도 모델 학습비용과 함께 평가해야 한다. WCL-P의 고정 버튼 primitive는 특정 접촉 태스크에서는 좋지만 GR00T C1 success80→70 하락하는 경우도 있어 무조건 더 낫지 않다.

03 / 설계와 학습

방법론 · 아키텍처

§III의 순서: ① Task graph를 명시하고 커피 8개 단계 approach/grasp/transport/place/press/re-grasp/transport/deliver에 stage-specific executor와 physical guard를 지정한다(press 후 wait는 executor 관리). ② 동일 grasped/placed/triggered predicate를 시연 구간 자르기, online 전이, 평가 지표의 기준으로 사용한다. ③ 접근·이동·대기는 navigation/wait executor가, 조작은 π0.5 또는 GR00T VLA가 맡는다. ④ 조작 직전 목표 물체에 상대적인 base stance를 정하고 base가 진동을 멈춘 후 gripper ready/carry posture로 시작한다. ⑤ 16-step action chunk에서 base velocity channel을 executor가 마스킹/대체하고 HOMIE(sim)/GR00T-WBC(real)가 하체를 추종한다. ⑥ guard 만족 시 다음 단계, 잡기 실패·stage confusion 시 retry/backedge, 비정상 drop 시 abort. 세계 좌표에 고정한 목표를 움직이는 base frame으로 재투영해 버튼 위치 오차를 억제한다.

DEEP DIVE / 01

모델 구조와 처리 흐름

개념적 처리 순서를 정리한 편집 다이어그램이며 원논문의 그림을 복제한 것은 아닙니다.

  1. 01

    01 전체 명령을 물리 단계 그래프로 분해

    커피 가져오기는 approach→grasp→transport→place→press→re-grasp→transport→deliver의 8개 단계로 나뉜다. 각 단계는 자연어 ℓ, executor c, 종료 guard g, 시간 예산 τ, 회복정책 ρ를 가진다. 머신 대기(wait)는 VLA가 0-action을 학습하는 대신 executor가 감시한다.

    s_k=(ℓ_k,c_k,g_k,τ_k,ρ_k); 8 stages + executor wait
  2. 02

    02 Predicate를 시연과 평가에서 공유

    grasped는 손가락 닫힘, wrist-object 근접, 물체 바닥 높이보다 lift의 AND 조건이다. placed는 표적 영역 내부/정지/손 열림, triggered는 장치 상태, dropped는 비정상 물체 낙하를 점검한다. 같은 물리 event를 offline segment end, online gate, evaluation criterion에 일관되게 연결한다.

    grasped ∧ placed ∧ triggered ... : guard-based state transitions
  3. 03

    03 VLA 행동과 기존 제어의 권한 분할

    시뮬레이션 정책 π0.5와 GR00T N1.6은 16-step chunk를 만들고 각각 32D·35D 상체/손/베이스 명령을 포함한다. 조작 stage에서는 base velocity를 executor가 대체/마스킹하고 보행은 navigation/WBC에서 처리한다. HOMIE(sim)와 GR00T-WBC(real)가 통합 control을 맡는다.

    Vision+language VLA local manipulation, executor locomotion/wait
  4. 04

    04 WCL: 세계 좌표와 목표 물체 기준 재정렬

    executor는 매 retry마다 현재 object pose에서 상대 base stance를 계산해 시작 자세를 재설정한다. 같은 workstation에서는 세계 좌표의 기준 base pose를 유지하고 오차가 바깥 임계값을 넘을 때만 correction, 안쪽에 들어오면 stop한다(hysteresis). 버튼 contact target도 world-anchored 후 로봇 frame으로 재표현한다.

    Object-relative stance + station keeping + world-anchored contact
  5. 05

    05 Guard 충족 여부에 따른 recovery

    각 chunk가 끝났다고 바로 다음 명령으로 넘어가지 않는다. lift/placed/triggered가 물리적으로 확인될 때만 advance한다. 실패 시 stance 복원 및 재시도, 머신 버튼 미작동인데 머그가 다시 손에 있으면 place stage로 reverse; unrecoverable dropped는 abort한다.

    Advance / Retry / Reverse / Abort; Algorithm1
  6. 06

    06 실험의 두 모델링 축 분리

    실험은 flat weights를 동일하게 유지한 채 executor off→FSM-only→PGX 구조를 바꾸고, 별도로 flat trained weights vs stage-trained weights를 변경한다. C0는 시연에서 본 위치, C1은 ±0.30m·±30°에서 시작하며, 각 task 당 엄격 성공조건(커피는 머신 trigger 필수)이 동일하다.

    Same weights ablation vs retrained stage model; C0/C1 evaluation
DEEP DIVE / 02

핵심 설계·학습 신호 해설

왜 그리퍼 닫힘을 성공으로 세면 안 되는가

로봇이 빈 공기를 쥐어도 closed signal은 true가 될 수 있다. PGX는 그리퍼 손목–물체 거리와 물체 lift를 함께 검사하므로 '잡았다'와 '손을 닫았다'를 다르게 다룬다. 이 predicate를 시연 분할/online gating/평가에 동일하게 쓰면 단계의 뜻이 맞아떨어진다.

읽기 포인트§III-B Eq3, Fig.2 top FSM and guards

Flat VLA보다 구조적 실행이 왜 낫나

긴 이동·대기 구간이 많은 시연에서 그대로 행동을 회귀하면 fine contact skill이 희석된다. PGX는 walking과 wait를 별도 controller로 넘기고 조작 직전 ready stance를 만들어 국소 skill의 시작 상태를 통제한다. 머신을 건너뛰고 컵을 배달해도 성공처럼 보이는 flat policy 오류는 device-trigger guard로 차단된다.

읽기 포인트Fig1 flat vs PGX; Fig4 skipped machine example

World frame lock과 pelvis frame drift

휴머노이드 몸통이 몇 cm 움직이면 pelvis-relative 버튼 위치가 비틀어진다. WCL은 작업대 기준 참조 자세를 유지하고 base drift의 두 임계값으로 correction을 켜고 끈다. 3초마다 지속 외란을 주입한 실험에서 p90 per-stage max drift가 54cm→9cm로 낮아졌다. 이것을 실환경 일상 주행 drift 일반 지표라고 부르지 않는다.

05 / 비판적 해석

한계와 비판적 검토

FSM/guard는 물체 pose, Vicon/joint feedback, 장치 state 등을 필요로 해 완전히 camera-only learned autonomy가 아니다. stage graph, object-relative stances, retry policy 등 수동 시스템 통합 비용도 있다. 실물은 Unitree G1 한 종류, 44 Quest demos, Vicon 외부 위치추적에 의존하며 실제 4단계 conditional completion과 시뮬 strict episode success를 혼용하면 안 된다. π0.5/GR00T의 모델별 stage training 차이가 있고 Table III에서 GR00T stage model이 기존 flat-weight PGX보다 80/80→35/35로 하락한다. WCL-P도 GR00T C1 80→70으로 악화되는 조건이 있다. 작업 전이에는 오히려 시간 오버헤드가 있다고 저자도 인정한다. HTML 목차 §I–V에 별도 Appendix가 없다.

RESEARCH LAB / EDITORIAL PROPOSAL

내 연구에 적용한다면?

아래는 논문 저자의 검증 결과가 아니라, 논문에서 출발해 설계한 **후속 실험 제안**입니다.

검증 가설

[편집 제안] 성능 향상의 주원인은 새 policy weights가 아니라 물리 predicate에 기반한 시작 상태 통제이므로, 외부 포즈 추정 품질이 나빠지면 PGX의 이득이 감소할 것이다.

구체적 실험 설계

[편집 제안] 시뮬 Unitree G1 커피 task에서 같은 GR00T flat weights와 동일50 demonstration, C0/C1≥100 episodes/seed 3 seeds를 고정해 flat, FSM-only, PGX, PGX+WCL-P를 재현한다. 물체 pose noise0/2/3/5cm, delay와 missed trigger detection, 외부 Vicon 제거 실험을 추가한다.

비교군·Ablation

[편집 제안] 실행 구조 없이 task prompt만 교체한 flat, stage prompt-only, FSM-only, base station-keeping-only, object-relative stance-only, full PGX, world-anchored button primitive로 분해한다. 동일 pose sensor 제공 여부를 통제한다.

기록할 지표

[편집 제안] full end-to-end strict SR와 stage-conditional SR, time-to-success, number retries, stage skips, base drift p90, button contact error(mm), emergency-stop·collision, 95% CI, 인력 소요 stage predicate 작성시간.

실패 해석·주의점

[편집 제안] Vicon을 쓰는 PGX와 image-only baseline을 같은 autonomy 수준으로 비교하지 않는다. 임계값이 잘못되면 성공 전이 착각이나 무한 retry가 발생할 수 있으며 실제 휴머노이드 테스트는 안전 가드가 필수다.
