Bind-WAM: Binding-Uncertainty-Guided Selective Future Imagination in World Action Models

Bind-WAM은 언어가 가리키는 물체가 불분명할 때만 미래 영상·행동을 함께 생성한다. LIBERO 98.6%/미래 상상 40.58%, 실물 3과제 평균 66.6%를 보고하지만, 의사라벨은 고비용 오프라인 모델과 조건별 임계값에 의존한다.

00 / ONE-MINUTE RECAP

핵심을 먼저 읽기

미래를 항상 상상하는 WAM과 미래 예측을 아예 끄는 WAM 사이의 중요한 중간 지점이다. '그릇을 접시 위에 놓아'에서 두 후보 그릇 중 무엇을 가리키는지 애매해지는 시점에만 joint video–action denoising을 호출한다. 미래 생성의 비율을 '무작위로 40% 실행'하는 것과 의도적으로 구분한 논문이다.

01 / 문제 정의

연구가 풀려는 문제

World-Action Model은 미래 영상과 행동을 함께 예측하면 실행 맥락에 도움을 줄 수 있지만, 물체가 잘 보이고 지시가 명확한 모든 step에서 장면을 새로 생성하면 지연과 계산비가 증가한다. 기존 Fast-WAM은 배포 시 미래 생성을 생략하고, joint WAM은 상시 생성한다. 예컨대 비슷한 컵 둘 사이에서 '왼쪽 컵'의 정체가 잠시 가려질 때만 미래 정보를 더 쓰고, 확실히 집은 뒤 테이블 위로 옮길 때에는 행동만 빠르게 생성할 방법이 필요한 것이다. 논문은 언어-객체 역할(binding)의 가시성·참조 불일치·정체성 변화를 라우팅 지표로 만든다.

02 / 핵심 기여

핵심 아이디어

훈련 과정에서 강한 시각/언어 모델이 전체 시연을 훑어 어떤 관측이 언어 지시의 target/reference 물체를 안정적으로 추적하지 못하는지 의사라벨을 만든다. 배포에는 이 무거운 모델 대신 6.65M 경량 불확실성 예측기만 올린다. 점수 U_t 자체나 이전 점수와의 차이가 threshold를 넘으면 미래 비디오+action을 공동 생성하고 그렇지 않으면 action-only 경로로 전환한다. 따라서 중요한 기여는 새 물리 예측 모델을 크게 만드는 게 아니라 언제 상상할지 결정하는 통제 신호다(Figure 2).

DEEP DIVE / 04

기존 연구와 무엇이 다른가?

Fast-WAM은 배포에서 미래 비디오를 끄고, joint WAM은 매번 예측한다. AdaWAM은 실행 단계 등을 바탕으로 동적 계산을 사용하지만 Bind-WAM은 명령이 특정 개체에 연결되는지(역할·가림·identity)를 명시적으로 신호화한다. 차별점을 확인하려면 '같은 평균 미래생성량'인 random/uniform router와 비교해야 한다. LIBERO 98%의 포화 상황에서 1pp 남짓의 차이보다 실물 소표본과 OOD 로봇의 calibration이 더 중요하다.

03 / 설계와 학습

방법론 · 아키텍처

§III-B offline pipeline: 시연의 역할 물체를 Qwen3-VL-32B로 추론하고 SAM 3.1 인스턴스 마스크·DINOv3 ViT-L/16 외형 추적으로 IoU·보임 여부·정체성 안정성을 기록한다. 역할 참조 IoU<0.3, 가림, 임베딩 cosine<0.9인 경우 불확실 라벨로 집계하며 32 frames/trajectory로 생성한다(Figure 3). §III-C에서 224² RGB와 명령을 받는 작은 ViT router(4 attention blocks/hidden256/6.65M)를 70/15/15 episode-level split, BCE+Brier 목적, 15 epochs로 학습한다. §III-D–F에서 Wan2.2-5B 기반 공유 WAM은 direct 시 action이 현재 프레임에만 attention, joint 시 미래 시각 token도 조건으로 사용한다. LIBERO 임계 U>=0.9976 또는 |ΔU|>=0.25면 joint, 매 10 환경 step마다 재계획한다. 무거운 Qwen/SAM/DINO는 배포에 사용하지 않는다.

DEEP DIVE / 01

모델 구조와 처리 흐름

개념적 처리 순서를 정리한 편집 다이어그램이며 원논문의 그림을 복제한 것은 아닙니다.

  1. 01

    01 | 언어가 지정한 객체의 역할을 정의

    'moka pot을 stove 위에 놓아'처럼 target과 reference 객체를 구분한다. 현재 영상만 보고 물체 식별이 불가능한 순간에는 행동을 선택해도 대상이 바뀌는 문제가 생긴다.

    instruction + RGB video → role-specific target/reference
  2. 02

    02 | 오프라인 시연에서 불확실성 의사라벨 생성

    Qwen3-VL-32B로 role box를 생성하고 SAM3.1로 마스크를 추적하며 DINOv3 feature similarity로 identity drift를 추정한다. 가림·IoU<0.3·cos<0.9가 있으면 불확실하다고 표시한다. 32 프레임/trajectory 등 offline라벨 조건을 유지한다.

    full demo → pseudo binding-risk y_t∈{0,1}
  3. 03

    03 | 6.65M 라우터를 별도 학습

    배포에서 Qwen/SAM/DINO 호출을 막기 위해 현재 224×224 RGB와 instruction을 입력으로 4-block lightweight predictor를 학습한다. 전체 episode를 기준으로 70/15/15로 나누고 weighted BCE+Brier로 보정을 유도한다.

    RGB+instruction → U_t binding uncertainty
  4. 04

    04 | 직접 경로와 미래 동시 생성 경로를 공유 모델에 둠

    Wan2.2-5B 기반 shared video/action expert를 학습하면서 direct route는 현재 시각 token에만 attention, joint route는 생성된 미래 시각 token까지 교차-attention한다. 각각 따로 정책을 배포하는 ensemble이 아니라 공통 가중치의 두 추론 모드다.

    current visual context → direct action OR joint future+action
  5. 05

    05 | 점수 수준과 변화량 모두로 분기

    LIBERO의 실험적 threshold는 U_t≥0.9976 또는 |U_t−U_t−1|≥0.25이다. 꾸준히 높은 불확실성과 갑자기 증가한 불확실성을 모두 감지하지만, 값은 benchmark 검증을 통해 선택된 하이퍼파라미터다.

    router threshold → 40.58% joint requests on LIBERO
  6. 06

    06 | 10 환경 step마다 관측·재계획

    선택된 경로만 실행해 action chunk를 만들고 실제 관측으로 다시 돌아온다. 성공률 외에도 joint inference 비율 및 성공 에피소드 완료시간으로 '상상을 아낀 대가'를 측정한다.

    act → observe → replan every 10 environment steps

실험과 주요 발견

✳

LIBERO 총 40과제(4 suites×10, 각 task 50 trials) 저자 재현 기준 Bind-WAM 98.6%, Fast-WAM 97.1%, ALWAYS-joint 98.4%; 공동 미래 생성은 40.58%에만 수행됐고 성공 에피소드 평균 완료시간은 11.71초 대 always-joint 15.7초(Table II). 7-task RoboTwin2에서는 clean 88.3%, randomized 87.0%로 joint 87.7/86.1보다 높지만 clean에서 AdaWAM 88.4%보다 0.1pp 낮다(Table III). 실물 HEXFELLOW 세 과제, 과제당 11회 실험 평균 66.6% 대 always-joint 57.6%, action-only 42.4%, 28.4% 미래 생성(Table IV). 같은 40% 안팎 미래 생성량을 가진 random 97.35%, uniform 97.50%보다 uncertainty router 98.60%로 높은 것은 발생 위치가 중요함을 시사한다(Table V).

05 / 비판적 해석

한계와 비판적 검토

오프라인 의사라벨 단계는 Qwen3-VL-32B·SAM3.1·DINOv3와 전체 시연을 요구하므로 학습 데이터/비용이 사라지지 않는다. 보이는 물체와 동일성 점수는 올바른 조작 목표나 동역학적 안전을 직접 증명하지 않고, router 오류나 threshold 이동에 취약하다. LIBERO 최적 임계값 0.9976은 다른 카메라·언어·물체에 무조건 이식할 수 없다. LIBERO가 거의 포화(98%대)라 1.2pp 차이는 실험 표준오차와 checkpoint 선택 효과를 고려해야 하며, Table II에 발표된 타 논문 baseline과 저자 재현 † baseline을 동일 훈련 조건으로 혼합 비교하지 않는다. Table IV는 11 trials/task만 있고 시간은 성공 에피소드만을 평균한 선택 편향이 있다. 공식 논문에는 별도 Appendix가 없으므로 본문 이상 세부 조건을 상상해 보완하지 않았다.

RESEARCH LAB / EDITORIAL PROPOSAL

내 연구에 적용한다면?

아래는 논문 저자의 검증 결과가 아니라, 논문에서 출발해 설계한 **후속 실험 제안**입니다.

검증 가설

[편집 제안] 미래 생성의 경제성은 불확실성 측정 정확도보다 '실제 action 실패를 예측하는 calibration'에 달려 있다.

구체적 실험 설계

[편집 제안] 동일 checkpoint와 40% imagination budget으로 컵 유사도, 가림 지속시간, 카메라 간 이동, 조명, 새로운 지시 대명사를 factorial design으로 교차한다. 새 task별 100회 실험과 동일 실패 seed를 사용한다.

비교군·Ablation

[편집 제안] uncertainty/entropy threshold, random/periodic, always-direct, always-joint, action confidence, force/occlusion-triggered safety stop. 라우터 경량화와 heavy pseudo-label 비용 모두 별도 로그.

기록할 지표

[편집 제안] strict success(95% Wilson CI), failed reference identification, joint call count, wall time all episodes, p95 end-to-end latency, GPU-hours of offline labeling + training + deployment.

실패 해석·주의점

[편집 제안] Qwen label bias/false-negative, target-reference 역할 전환, threshold 보정 누락, 실패 episode에서의 완료시간 편향과 task-specific router overfitting.
