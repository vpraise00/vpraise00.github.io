DexVLA: Vision-Language Model with Plug-In Diffusion Expert for General Robot Control

DexVLA는 10억 파라미터급 diffusion 행동 전문가를 별도로 사전학습한 다음 VLM과 결합하는 3단계 커리큘럼을 제안한다. Shirt folding 0.92와 Laundry folding 0.40은 성공률이 아닌 단계별 부분점수라는 점까지 원문을 검증한다.

00 / ONE-MINUTE RECAP

핵심을 먼저 읽기

언어를 이해하는 거대 VLM만 확장할 것이 아니라, 실제 움직임을 생성하는 1B diffusion expert를 먼저 다양한 로봇에서 사전학습하고 목표 로봇에 정렬하자는 제안입니다. (arXiv v3 §3, Figure 2)

⌁ DEEP TECHNICAL REVIEW연구자용 상세 해설

독해 핵심: 이 논문은 ‘셔츠를 접었다’는 시연 홍보가 아니라, 행동 전문가 규모와 훈련 순서가 왜 중요한지를 원문 Figure 2·Table 1·Appendix A–D를 통해 비교할 수 있는 실험입니다. 그림은 저자 Figure 1(작업 사례)과 Figure 2(3단계 학습 구조)를 설명 위치에 두었습니다. 평가 점수와 strict success를 구분합니다.

01 / 문제 정의

연구가 풀려는 문제

로봇이 ‘셔츠를 접고 빨래통을 정리해’라는 언어 명령을 받아도, 시각·언어 이해만으로는 젖은 천의 변형이나 양팔 동기화를 제어하기 어렵습니다. OpenVLA 등의 언어 중심 VLA는 VLM 규모가 커도 실제 연속 관절 궤적을 학습하는 부분이 상대적으로 제한될 수 있습니다. 또 하나의 정책으로 그리퍼, 양팔, 다지손의 제어 공간을 섞으면 출력 차원과 운동 습관이 달라 충돌합니다. DexVLA는 표현 학습과 운동 전문성 사이의 불균형, 이종 로봇 시연을 재사용하기 어려운 문제, 2분 이상 과제에서 단계 누락이 잦은 문제를 함께 해결하려 합니다. (§1–3)

02 / 핵심 기여

핵심 아이디어

Qwen2-VL 기반 VLM은 영상·지시와 현재 과제 단계에서 생성할 reasoning/action 토큰을 담당하고, 실제 연속 행동은 별도 ScaleDP 계열 diffusion transformer가 생성합니다. 여러 embodiment의 행동 출력에는 별도 head를 두어 공유 모터 능력과 물리 제어 공간의 차이를 분리합니다. 먼저 행동 전문가만 이종 데이터로 훈련(Stage 1)하고, 특정 로봇의 데이터에서 VLM–전문가 연결을 정렬(Stage 2), 긴 작업은 substep 언어 감독을 포함한 맞춤 후속학습(Stage 3)으로 적응합니다. 이 ‘plug-in’ 구성과 3단계 학습이 기여의 핵심입니다. (§3.1–3.2, Figure 2)

DEEP DIVE / 04

기존 연구와 무엇이 다른가?

OpenVLA의 tokenized action prediction, π0의 flow-matching policy와 달리 DexVLA의 실험 핵심은 1B diffusion policy 자체의 독립 사전학습과 단계적 정렬입니다. π0와 달리 모델 내부에서 substep language를 생성해 motor expert에 전달하는 설정을 비교하되, 선행 연구의 추가 고수준 정책 여부와 세부 학습 예산이 다름을 인정해야 합니다.

03 / 설계와 학습

방법론 · 아키텍처

입력은 다중 카메라 영상과 언어 명령입니다. VLM 시각 토큰은 이어 붙여 처리하고 reasoning 토큰과 action 토큰을 생성합니다. action 토큰은 LayerNorm과 두 선형층으로 diffusion expert 조건에 사상하고, reasoning 토큰은 FiLM 층으로 행동 정책의 내부 특징을 조절합니다. expert는 ScaleDP transformer 계열이며 embodiment별 head를 선택해 액션 청크를 생성합니다. Stage 1에서는 VLM을 제외하고 image/language encoder를 포함한 expert를 이종 로봇 시연으로 사전학습합니다. Stage 2에서는 expert의 독립 시각·언어 구성 요소를 제거하고 VLM과 연결하여 대상 embodiment 데이터로 정렬합니다. Stage 3는 어려운 후속 과제의 데모로 정교화합니다. 약 5초 간격의 substep 문구는 단순 입력 메모가 아니라 모델이 중간 출력으로 생성하도록 학습합니다. (§3, Appendix D)

DEEP DIVE / 01

모델 구조와 처리 흐름

개념적 처리 순서를 정리한 편집 다이어그램이며 원논문의 그림을 복제한 것은 아닙니다.

  1. 01

    01 · 관측과 명령의 결합

    카메라 다중 뷰와 자연어 명령을 Qwen2-VL에 넣어 공통 표현을 만듭니다. 영상 토큰은 카메라별 추출 후 연결되며 reasoning/action 두 종류의 출력 감독이 존재합니다.

    입력: RGB×다중 시점 + language
  2. 02

    02 · 1B diffusion expert 독립 사전학습

    Stage 1은 대규모 이종 embodiment 시연을 모터 expert로 학습시키며 VLM을 같이 학습하지 않습니다. 이 단계에서는 expert용 독립 시각·언어 encoder를 사용하고 로봇 형태별 action head로 다른 차원의 제어를 처리합니다.

    훈련: cross-embodiment demonstrations → motor prior
  3. 03

    03 · Stage 2의 VLM–expert 정렬

    대상 로봇 데이터를 사용해 Qwen2-VL의 action 토큰을 projection→diffusion expert의 조건으로 연결합니다. expert 자체 encoder의 중복 영상·언어 부분을 제거하고 reasoning 토큰을 FiLM으로 주입합니다.

    VLM tokens → connector + FiLM → action expert
  4. 04

    04 · Stage 3의 long-horizon 후속학습

    세탁물 접기와 까다로운 상 차리기처럼 수 분에 걸친 작업은 각 시연의 중간 단계 설명을 모델이 스스로 출력하도록 supervised training합니다. 원문은 약 5초 주기의 substep 라벨을 설명합니다.

    출력: learned substep descriptions + continuous action chunks
  5. 05

    05 · 실물 평가의 점수 해석

    각 과제 10회 반복에서 미리 정한 중간 완료 기준으로 부분점수를 산정합니다. 모델이 한 단계만 수행한 경우도 일부 점수를 받을 수 있으므로 0.92를 92% 완전성공으로 바꿔 말하지 않습니다.

    평가: 10 trials, task-specific partial-credit rubric
DEEP DIVE / 02

핵심 설계·학습 신호 해설

FiLM으로 reasoning이 행동을 조절

VLM의 reasoning 토큰은 컨텍스트 문장을 생성하는 데 그치지 않고 FiLM(feature-wise linear modulation)을 통해 전문가의 입력/특징을 scale·shift합니다. ‘지금 접는 중인지 펴는 중인지’에 따라 같은 손목 위치에서도 다음 액션을 다르게 조건화하는 인터페이스입니다. (§3.1)

읽기 포인트FiLM 제거 ablation과 모터 expert 규모 ablation은 서로 다른 질문입니다.

Embodiment head와 공유 transformer

트랜스포머 모터 backbone은 이종 시연의 운동 규칙을 공유하지만 서로 다른 로봇의 출력 head는 분리합니다. Franka 그리퍼와 양팔 AgileX의 실제 action vector 차이를 한 출력 차원에 억지로 결합하지 않는 설계입니다. (Figure 2)

읽기 포인트head 공유가 곧 테스트 시 미학습 로봇에 대한 완전 zero-shot을 보장하지 않습니다.

명시적 외부 계획과 내부 substep의 차이

DexVLA는 학습 과정에서 substep language를 예측하여 행동 expert에 주입합니다. Appendix B의 hard table bussing 비교에서 SayCan 외부 substep(0.58)보다 통합 reasoning(0.70)이 높지만, 외부 계획 전체의 우열을 일반화할 근거는 아닙니다.

읽기 포인트SayCan 업데이트 간격과 학습 데이터가 통제되는지도 재현해야 합니다.

Billion-scale action head 가설

셔츠 접기 정규화 점수는 93M UNet 0.17→410M 0.63→1B 0.92로 증가합니다. 이는 저자 설정에서 용량 증가와 성능의 동반 변화를 보여주지만 각 모델의 데이터량·추론비용·하이퍼파라미터를 통제한 인과 추정과는 구분해야 합니다.

읽기 포인트서로 다른 action expert의 크기뿐 아니라 네트워크 유형도 다릅니다.

05 / 비판적 해석

한계와 비판적 검토

핵심 수치는 단순 binary success가 아니라 과제별 10회 수행에서 부분완수 점수입니다. 실물 대상 과제, 훈련 시연 수, 로봇 형태와 사전학습 데이터가 달라 모든 수치를 다른 논문의 성공률과 직접 비교하면 안 됩니다. 빨래 접기는 ‘언어 지시만으로 평가’하지만 실제로는 해당 과제 Stage 3 후속학습을 수행했으므로 무학습 zero-shot이 아닙니다. Appendix A.5의 다지손 전이는 1 DoF로 제약한 시험이며 전 손가락 자유도 일반화 증거가 아닙니다. expert 규모를 키우는 효과와 3단계 curriculum 효과를 완전히 분리한 동등 계산량 대조도 필요합니다. 원문 수치가 표본 수가 작은 실물 실험이라는 점을 유의해야 합니다. (§4, Appendix A–D)

RESEARCH LAB / EDITORIAL PROPOSAL

내 연구에 적용한다면?

아래는 논문 저자의 검증 결과가 아니라, 논문에서 출발해 설계한 **후속 실험 제안**입니다.

검증 가설

Cross-embodiment expert Stage 1이 모델 크기 증가 자체보다 적은 target-robot demos에서 중요한 성능 개선을 제공할 것입니다.

구체적 실험 설계

Franka gripper와 bimanual UR5에 대해 각각 25/50/100회의 target 시연을 고정하고, 동일한 이미지 인코더 및 행동 출력 빈도 조건에서 93M/410M/1B expert를 훈련합니다. 10회보다 충분히 많은 seed×task×trial을 확보하고 rubric 항목별 누락을 기록합니다.

비교군·Ablation

(a) Stage2 from scratch, (b) Stage1+Stage2, (c) Stage1+Stage2+Stage3, (d) substep 제거, (e) FiLM 제거, (f) 동일 FLOPs 작은 expert.

기록할 지표

Strict full success와 partial score를 별도 보고; stage-level completion, unseen-object success, action jerk, p50/p95 end-to-end latency, GPU-hour 및 collision 횟수.

실패 해석·주의점

학습 시연 수·expert 크기·고수준 substep 주석 비용을 통제하지 않으면 커리큘럼의 기여를 과대평가할 수 있습니다.
