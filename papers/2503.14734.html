GR00T N1: An Open Foundation Model for Generalist Humanoid Robots

GR00T N1은 언어·영상의 과제 이해(System 2)와 고주파 로봇 행동 생성(System 1)을 결합한 휴머노이드 VLA입니다. 데이터 피라미드·16-step flow-matching, 서로 다른 embodiment의 상태·행동 인코더, RoboCasa/DexMG/GR-1의 비교 실험과 원문 Appendix D/F까지 분석합니다.

00 / ONE-MINUTE RECAP

핵심을 먼저 읽기

GR00T N1은 범용 휴머노이드의 두 난제를 동시에 다룹니다. 이미지를 보고 과제를 해석하는 VLM과 매 순간 관절·그리퍼 행동을 만드는 DiT를 분리하면서, 데이터가 적은 개별 몸체로 전이할 수 있도록 다양한 소스의 훈련 신호를 합칩니다. (원문 §2–4)

⌁ DEEP TECHNICAL REVIEW연구자용 상세 해설

읽기 포인트: GR00T N1의 본질은 'VLM + DiT'라는 부품 목록보다, 이종 데이터의 비균일한 행동 정의를 구조가 다른 로봇에 재사용 가능한 정책으로 바꾸는 인터페이스와 학습 단계입니다. Figure 1의 데이터 피라미드, Figure 2의 두 모듈, Table 2·3의 독립 평가 단위를 차례로 읽겠습니다. (arXiv v2 §2–4, Appendix B/D/F)

01 / 문제 정의

연구가 풀려는 문제

사람의 '왼쪽 선반에 용기를 넣으세요'라는 지시를 로봇이 듣는 상황을 생각해 보겠습니다. 지시의 물체·도착 위치를 이해하는 일과 손가락 압력·양팔 이동을 10여 밀리초 단위로 갱신하는 일은 서로 다른 계산 문제입니다. 단일 로봇 시연은 수집 비용이 매우 비싸고, 로봇별 관절 수·카메라·행동 표현이 달라 같은 학습 데이터로 묶기 어렵습니다. 기존 Diffusion Policy를 특정 과제에 처음부터 훈련하면 새로운 물체·환경·데이터 부족 상황에서 약해집니다. (서론, §2)

02 / 핵심 기여

핵심 아이디어

직관적인 사례: 팔로 컵을 잡아 다른 손에 넘길 때, System 2가 '컵을 잡아 상대 손에 건네야 한다'는 장면·언어 맥락을 인코딩하고 System 1이 해당 로봇의 상태에서 16개의 연속 행동 후보를 복원합니다. Eagle-2 VLM 토큰과 로봇별 상태/행동 인코더를 DiT에서 결합하므로 같은 개념적 정책도 Franka 단팔·양팔 Panda·GR-1 휴머노이드 등 상이한 구동 인터페이스로 전이될 수 있습니다. 다만 '아무 로봇에서나 즉시 작동'한다는 주장은 아닙니다. (Figure 2, §2.1)

DEEP DIVE / 04

기존 연구와 무엇이 다른가?

기존 per-task Diffusion Policy나 BC Transformer가 로봇마다 적은 데이터를 처음부터 학습한다면, GR00T는 인터넷 이미지·언어 사전학습을 가진 System2와 embodiment별 encoder가 붙은 System1 DiT를 결합하고 이종 비디오/로봇데이터로 pretrain합니다. 그러나 공정한 비교를 위해 목표 task 데모 수·설정뿐 아니라 사전학습 규모/compute도 기록해야 하며, Figure1의 데이터 피라미드가 causal ablation 결과인 것처럼 해석하지 않습니다.

03 / 설계와 학습

방법론 · 아키텍처

출발은 인터넷으로 사전학습된 Eagle-2 비전언어 모델이며 공개 GR00T-N1-2B 체크포인트는 총 2.2B(그중 VLM 1.34B)입니다. 영상과 텍스트 토큰이 System 2에서 처리되고, proprioception과 noised action을 embodiment별 MLP가 공통 임베딩으로 투영합니다. DiT의 cross-attention이 VLM 정보를 참조해 flow matching으로 길이 H=16 행동 chunk를 반복 디노이징합니다. 데이터 피라미드는 하단의 대량 인간 비디오·합성 영상 및 가상 행동, 그 위의 로봇 시연 등 출처와 embodiment 적합도가 다른 데이터를 조합합니다. 학습은 광범위 사전학습 후 목표 로봇/과제의 소규모 post-training으로 이어지며 일부 비디오에는 latent action 또는 inverse dynamics로 얻은 pseudo-action을 부여합니다. (Figure 1–2, §2–3, Appendix F)

DEEP DIVE / 01

모델 구조와 처리 흐름

개념적 처리 순서를 정리한 편집 다이어그램이며 원논문의 그림을 복제한 것은 아닙니다.

  1. 01

    01. 서로 다른 종류의 데이터에 역할 부여

    실제 로봇 demonstration은 해당 몸체의 센서·제어 기준에 정렬되지만 규모가 작고, 인간 비디오와 합성 비디오는 크지만 직접적인 로봇 action이 부족합니다. 데이터 피라미드는 양이 많은 약한 신호와 양이 적은 몸체별 정밀 신호의 층위를 묘사합니다. 이를 '모든 영상에 정확한 로봇 행동이 있다'고 해석하면 안 됩니다. (Fig.1, §2.2–3)

    real demos + human video + simulation + neural trajectories
  2. 02

    02. 영상에 학습 가능한 행동 신호 붙이기

    인간 비디오나 생성된 영상은 로봇 관절 각도 정답이 없으므로 latent action model 또는 inverse dynamics model(IDM)이 시각 상태 변화에서 행동 유사 라벨을 추정합니다. 이 라벨은 실제 물리적 제어값의 완전한 ground truth가 아닙니다. 후속학습 시 neural trajectory의 추가 전이 효과를 별도로 평가합니다. (§2.2, Appendix F)

    unlabeled visual transition → latent / IDM pseudo-action
  3. 03

    03. Eagle-2 System 2에서 장면과 지시 인코딩

    224×224 이미지 패치와 자연어를 Eagle-2 VLM에 입력해 언어적 목표·물체 맥락이 있는 토큰을 얻습니다. 공개 N1-2B는 총 2.2B 중 VLM 1.34B, System 2가 정책 출력과 독립된 자동 계획기를 실행한다는 뜻은 아닙니다. (§2.1)

    observations + instruction → multimodal context tokens
  4. 04

    04. Embodiment별 상태와 행동을 공유 공간으로 변환

    로봇마다 관절 수·end-effector 제어·그리퍼가 달라서 state/action을 동일한 벡터 길이로 무조건 덧붙일 수 없습니다. 각각의 MLP encoder/decoder를 두어 공유 DiT가 쓰는 토큰 공간으로 바꾸고, diffusion time을 noisy action에 조건화합니다. (Fig.2, §2.1, Appendix E)

    robot-specific state/action MLP → shared action tokens
  5. 05

    05. DiT flow matching으로 16-step 행동 chunk 생성

    DiT는 VLM 토큰에 cross-attention하고 robot state+noise를 받아 denoising을 반복해 H=16 액션을 생성합니다. 논문 보고 16-action chunk 생성에 L40 bf16 약 63.9ms이며 로봇 제어 파이프라인 전체의 네트워크·센서 지연은 포함하지 않습니다. (§2.1, Figure 2)

    noisy 16-step actions + VLM context → denoised actions
  6. 06

    06. 사전학습→로봇별 후속학습→평가 조건 분리

    광범위 데이터로 사전학습한 뒤, RoboCasa·DexMG·GR-1 각 task별 30/100/300 시연 조건에서 미세조정합니다. Appendix D의 pretrain batch 16,384/200k steps와 posttrain batch 128 또는 1,024/20–60k steps를 섞어 단일 동일 예산 실험으로 기술하지 않습니다. (§4.4, Appendix D)

    generalist checkpoint → target-embodiment adaptation
DEEP DIVE / 02

핵심 설계·학습 신호 해설

System 2/1은 느린 '말'과 빠른 '손'의 조합

언어 이해와 모터 제어가 필요한 temporal frequency가 다릅니다. 논문은 System 2 10Hz(L40 기준), System 1 120Hz로 설명하지만 모델 모듈의 동작 설명이지 두 개의 독립 CPU 프로세스 성능을 약속하는 수치가 아닙니다.

읽기 포인트실물은 실제 제어 주기/trajectory execution/replanning latency를 함께 측정합니다.

H=16 flow matching과 diffusion policy baseline의 차이

두 접근 모두 미래 action chunk를 생성할 수 있으나 GR00T는 VLM 의미 토큰과 robot-specific state/action을 함께 조건화하고 pretraining의 이득을 목표 로봇에 전이합니다. 단지 확산모델을 사용했다는 점만으로 새로운 것은 아닙니다.

읽기 포인트Table2에서 training demos/task=100 고정, 환경 구성/백본/학습단계를 비교합니다.

Data pyramid와 pseudo-actions의 trade-off

인간 행동을 로봇에 매핑할 때 embodiment mismatch가 생깁니다. Latent action이나 IDM 라벨은 대량 영상의 temporal affordance를 활용하는 우회로지만, physical contact fidelity까지 갖춘 것은 아닙니다.

읽기 포인트원본 비디오/latent/IDM를 동일 데이터량·학습 compute로 ablate해야 합니다.

실물 처음 보는 대상에 대한 pretrain-only 11.5/15는 grasp는 했으나 place 실패 시 0.5를 준 결과입니다. strict 성공 11.5건이라고 부르면 잘못된 성공률 해석입니다.

읽기 포인트Appendix B 및 §4.4 평가단위와 fractional scoring을 함께 기록합니다.

05 / 비판적 해석

한계와 비판적 검토

이 연구는 실험대 수준의 선택된 조작 과제와 제한된 로봇 구성에 대한 저자 실험입니다. 휴머노이드의 자유로운 보행·전신 안전이나 미지의 모든 환경 일반화를 증명하지 않습니다. System 2를 약 10Hz, System 1을 120Hz로 기술하지만 특정 GPU·스트림/하드웨어 조건이며 '모든 로봇에서 120Hz 보장'이 아닙니다. 사전학습·합성영상·후속학습을 동시에 바꾸면 어느 요소가 유효했는지 분리하기 어렵습니다. 11.5/15의 76.6%는 부분 점수 0.5가 포함된 저자 정의이므로 11.5회의 binary 완전 성공이 아닙니다. 원문 비교에는 데이터 출처·로봇 embodiment별 confound가 남습니다.

RESEARCH LAB / EDITORIAL PROPOSAL

내 연구에 적용한다면?

아래는 논문 저자의 검증 결과가 아니라, 논문에서 출발해 설계한 **후속 실험 제안**입니다.

검증 가설

같은 목표로봇 학습 예산에서 사전학습된 System2·DiT와 비디오기반 pseudo-action 학습을 같이 쓰면 low-data 실물 task 성공률이 개선되지만, pseudo-action의 domain mismatch가 심하면 이득이 약해집니다.

구체적 실험 설계

RoboCasa 24 tasks와 GR-1 tabletop 하위 4 categories에서 30/100/300 demos per task, 3 seeds, 원본 hyperparameters의 action horizon16/optimizer 유지, 목표 객체 OOD split 고정; 실제 로봇에는 안전 중단 스위치와 latency 모니터링을 둡니다.

비교군·Ablation

DP from scratch, BC Transformer, GR00T pretrained+target fine-tune, frozen System2, no human video, no IDM neural trajectories, same-sized synthetic trajectory augmentation.

기록할 지표

strict whole-task success, partial progress(별도), category macro & task-weighted average, sample efficiency, p50/p95 action inference, GPU-hours, 안전 정지 횟수.

실패 해석·주의점

대형 VLM pretraining compute와 합성영상 비용 차이를 동일 fine-tuning data로 가려서는 안 됩니다. 11.5/15의 fractional partial credit은 strict success에서 제외하고, 실물 실패도 보존합니다.
