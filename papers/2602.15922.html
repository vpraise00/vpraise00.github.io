World Action Models are Zero-shot Policies

DreamZero는 14B 비디오 확산 backbone으로 미래 영상과 행동을 공동 예측하는 World Action Model이다. 다양한 로봇 활동 500시간에서 학습한 뒤 새 동작·환경·기종으로 일반화하며, Figure 4의 causal DiT·KV cache와 Table 2의 성공률이 아닌 진행률을 정밀 구분한다.

00 / ONE-MINUTE RECAP

핵심을 먼저 읽기

WAM의 핵심을 '미래를 생성해 사람이 눈으로 확인한다'가 아니라 비디오 예측을 행동 예측의 물리적 감독으로 사용하고, 실제 관측으로 KV를 갱신하는 14B 폐루프 정책으로 파악한다. (§3, Figure 4)

01 / 문제 정의

연구가 풀려는 문제

'레몬을 접시에 놓아라'처럼 학습 시연이 많은 조작은 VLA가 잘할 수 있지만, 훈련 데이터에서 거의 보지 못한 신발끈 풀기·햄버거 부채질·도구 다루기 같은 동작은 언어 이해만으로 구현할 수 없다. VLA의 텍스트-이미지 사전학습은 '어떤 물체인가'에 강하지만 물체가 시간에 따라 어떤 힘·접촉으로 변하는지는 약하게 감독한다. 반면 기존 world model과 액션 모델을 따로 돌리면 비디오와 모터 시퀀스가 불일치하고 추론시간도 폭증한다. (§1–3)

02 / 핵심 기여

핵심 아이디어

DreamZero는 웹 비디오로 사전학습된 Wan 계열 14B 이미지-비디오 DiT를 직접 '행동을 수행하는 세계모델'로 바꾼다. 주어진 장면에서 '다음 몇 프레임이 이렇게 바뀐다'와 '그 변화를 만드는 모터 동작은 이것이다'를 한 번의 공동 noise-prediction 목표로 학습한다. 예컨대 컵을 집어 쟁반에 놓는다면 '컵이 공중으로 이동해 놓이는 미래'를 그리는 잠재공간과 팔의 동작이 같은 네트워크에서 정렬된다. 다만 생성된 영상이 반드시 물리적으로 옳다는 보장은 없고, 실패가 잘못된 비디오 예측에서 시작할 수 있다. (Figure 1·4, §3)

DEEP DIVE / 04

기존 연구와 무엇이 다른가?

SmolVLA/π0 같은 VLM→action 방식과 다르게 DreamZero는 비디오 DiT에서 출발해 시간적 세계 변화를 직접 조건화한다. 이 차이를 단순하게 14B와 3B의 크기 차이로 환원할 수는 없다. Table 4에서 같은 크기의 VLA 비교와 5B/14B 비교를 수행하지만 하드웨어·데이터·architecture 변경을 완벽하게 매칭한 보편적 인과 증거는 아니다. WAM의 진짜 검증 주제는 비디오 예측 품질이 실패 회복과 새로운 모션을 얼마만큼 개선하는지, 그리고 이를 20Hz 저가 제어기까지 확장할 수 있는지다.

03 / 설계와 학습

방법론 · 아키텍처

영상은 VAE latent, 명령은 text encoder, 관절상태는 state encoder로 들어간다. 행동은 encoder/decoder를 거쳐 미래 비디오 latent와 함께 autoregressive causal diffusion transformer에서 flow matching으로 공동 denoise한다. 학습에서는 과거 clean video chunk를 문맥으로 두고 다음 비디오·action chunk에는 노이즈를 준 채 teacher forcing한다. 추론 때는 매 chunk 후 실행된 실제 카메라 프레임으로 KV cache의 예측 과거를 교체하는 feedback 구조를 쓴다(Figure 4). 느린 비디오 denoising 문제에는 DreamZero-Flash의 video/action 독립 시간 스케줄, 캐싱, 정밀도 및 GPU 병렬화, 비동기 action 실행으로 대응한다(§3.2, Appendix C·D).

모델 구조와 처리 흐름

개념적 처리 순서를 정리한 편집 다이어그램이며 원논문의 그림을 복제한 것은 아닙니다.

  1. 01

    초기화: 물리 시간축이 있는 사전학습 모델

    텍스트 이미지 VLM이 아니라 Wan 이미지→비디오 확산 14B DiT를 초기화한다. 비디오로 학습한 시간적 물리 변화 선험을 이용한다.

    pretrained Wan I2V 14B
  2. 02

    세 종류의 조건부 입력

    과거 카메라 영상은 VAE에, 명령은 text encoder에, 자기수용 센서는 state encoder에 연결한다. 로봇 action은 별도 encoder/decoder를 거쳐 비디오 토큰과 정렬한다.

    visual context + instruction + proprio
  3. 03

    Teacher-forced chunk 공동 학습

    한 chunk의 미래 영상 latent와 행동 latent에 서로 다른 노이즈를 주고 공유 DiT에서 시간별 velocity를 맞춘다. 과거 비디오 chunk의 깨끗한 문맥은 현재 noisy chunk의 정보 흐름을 지원한다.

    joint flow-matching: future video & actions
  4. 04

    자기회귀 예측과 환경 실행

    미래 video latent와 action chunk를 함께 denoise해 비디오/행동 decoder로 보낸다. 로봇은 action chunk를 실행하며, 실제 카메라 관측이 들어오면 cache의 생성 문맥을 덮어쓴다. 장기 rollout의 영상 drift를 줄이기 위한 핵심 폐루프이다.

    predictions → execute → real observations
  5. 05

    Flash의 비디오·행동 noise schedule 분리

    액션 채널과 비디오 채널이 동일 횟수로 denoise해야 한다는 가정을 버리고 독립된 noise-time 분포를 준다. 적은 추론 스텝의 품질 저하를 완화한다. (Table 3, Appendix D)

    1-step Flash: 150 ms/chunk
  6. 06

    고속 제어의 하드웨어·시스템 경로

    CFG 병렬화, cache, 연산 kernel 최적화와 양자화, async chunk execution을 결합한다. 보고된 최대 38배 향상 및 7Hz는 2×GB200 고사양 하드웨어 조건에서 측정한 시스템 수준 결과다.

    2×GB200 / ~7 Hz
DEEP DIVE / 02

핵심 설계·학습 신호 해설

왜 미래 영상이 액션 감독으로 작용하나?

영상 공간의 시각적 변화는 언어보다 접촉·모션의 결과를 직접 반영한다. 예측된 다음 장면을 만드는 action의 inverse-dynamics 관계를 함께 학습하면 VLA의 '물체를 가리키기만 하는' 실패를 일부 보완할 수 있다. 단, 이 논문에서 비디오는 미래를 보장하는 시뮬레이터가 아니다.

읽기 포인트원문 §3와 Figure 4의 비디오·행동 공동 denoise 헤드를 따라갈 것

Teacher forcing과 KV cache의 충돌 방지

훈련에서 clean 과거에 조건화하는 동안 추론에서는 과거 예측이 누적될 수 있다. 현실에서 다음 관측을 얻을 수 있는 로봇의 장점을 활용해 그 관측으로 autoregressive cache를 갱신한다. (Appendix C, Figure 4)

05 / 비판적 해석

한계와 비판적 검토

'제로샷'은 해당 AgiBot/DROID 평가 집합의 작업과 환경에 대한 미학습 조건이며 임의의 로봇·현실세계 보장과 다르다. 전체 모델 14B는 데이터센터 GPU 두 대(GB200)를 필요로 하며 저가 에지 장치에 즉시 이식되는 7Hz가 아니다. 아울러 모델은 수초 단위 반응형 System 1이며 6초 정도의 짧은 visual memory, 밀리미터 수준 조립의 부정확성, 영상 환각 전이 문제를 논문 §6이 지적한다. Table 4 AR vs BD는 둘 다 progress 50%지만 AR의 유연한 캐싱·동작 매끄러움을 별도로 보고한다; 'BD보다 성공률 우월'은 성립하지 않는다.

RESEARCH LAB / EDITORIAL PROPOSAL

내 연구에 적용한다면?

아래는 논문 저자의 검증 결과가 아니라, 논문에서 출발해 설계한 **후속 실험 제안**입니다.

검증 가설

미학습 물리 동작의 개선은 액션 디코더만 키우는 것보다 비디오 예측의 물리적 정확도와 다양한 상태–행동 대응을 학습할 때 커진다.

구체적 실험 설계

DROID subset에서 seen/unseen verbs를 분리한 10–20개의 평가 과제를 고정하고, 500h 같은 큰 규모의 재현이 어려우면 공개된 로봇 영상으로 데이터 다양성(물체·표면·관찰 각도)과 반복 횟수를 통제한다. 녹화된 실제 rollout의 action·영상 동기화를 공통 프로토콜로 보존한다.

비교군·Ablation

공개 DreamZero checkpoint/action readout, video-loss 제거, AR vs BD, 5B vs 14B, repetitive vs diverse hours-matched, Flash1-step vs standard4-step. 동일 시간/steps과 hardware cost를 따로 명시한다.

기록할 지표

strict full completion, partial progress, dynamic object contact error, predicted future vs real frame warping error, action jerk, p95 chunk latency, 배포 GPU-hour, 성공당 비용.

실패 해석·주의점

비디오 생성이 보기에는 그럴듯해도 물리적으로 틀릴 수 있다. 미학습 과제 10개만으로 범용성을 일반화하지 말고 장기 기억(6초 이후), 모터 안전, 센서 dropout 및 sub-centimeter 조립을 별도 실패 범주로 기록한다.
