00 / ONE-MINUTE RECAP

핵심을 먼저 읽기

ALOHA의 50Hz 양팔 시연과 ACT의 CVAE 행동 chunk·temporal ensemble을 연결한다. 실물 배터리 삽입 96%, 지퍼 88%, Velcro 20%의 대비와 chunk 길이·CVAE ablation을 분석한다.

⌁ DEEP TECHNICAL REVIEW연구자용 상세 해설

저렴한 로봇은 반복 위치 정확도와 센서 정밀도가 제한되지만 물체의 작은 상대 변화를 영상에서 관찰하고 피드백하면 복잡한 접촉 과제도 가능할 수 있다. 한 timestep씩 지도학습하면 50Hz 제어에서 수백 번의 오차가 누적되고, 시연자가 잠시 멈추거나 다른 경로를 선택한 데이터에서는 현재 관측만으로 다음 행동이 결정되지 않는 경우가 있다. ALOHA는 데이터를 수집하는 시스템, ACT는 이 데이터로 학습하는 정책이다. 논문은 일반 목적 VLA가 아니라 과제별 학습으로 모방학습의 horizon·다중 모드 문제를 완화하는 방법을 제시한다. FAST와 OpenVLA-OFT의 chunk를 이해하는 데도 중요한 선행 연구다.

01 / 문제 정의

연구가 풀려는 문제

저렴한 로봇은 반복 위치 정확도와 센서 정밀도가 제한되지만 물체의 작은 상대 변화를 영상에서 관찰하고 피드백하면 복잡한 접촉 과제도 가능할 수 있다. 한 timestep씩 지도학습하면 50Hz 제어에서 수백 번의 오차가 누적되고, 시연자가 잠시 멈추거나 다른 경로를 선택한 데이터에서는 현재 관측만으로 다음 행동이 결정되지 않는 경우가 있다. 02 / 핵심 기여

핵심 아이디어

배터리를 리모컨에 넣는 동작을 떠올리면, 한 손이 리모컨을 고정하고 다른 손은 배터리 각도를 바꾸어 밀어 넣는다. 매 20ms에 팔 목표를 독립적으로 출력하면 앞선 동작과 서로 모순된 작은 진동이 생길 수 있다. ACT는 미래 여러 step을 한꺼번에 출력해서 연속 행동을 묶되, 매 순간 새 관측에서 다시 예측해 이전 계획과 같은 시간의 목표를 부드럽게 합친다. 학습 중에는 시연의 스타일을 설명하는 잠재 변수 z를 사용하고 실제 추론에서는 z=0으로 결정적 행동을 생성한다. 따라서 CVAE가 있다고 매 제어마다 여러 후보를 샘플링하는 것은 아니다.

DEEP DIVE / 04

기존 연구와 무엇이 다른가?

Diffusion Policy는 잡음에서 action trajectory를 여러 단계에 걸쳐 생성한다. ACT는 CVAE를 학습하지만 평가에서는 결정적 chunk를 한 번의 decoder pass로 생성하고 여러 시점의 예측을 평균한다. FAST는 자기회귀 VLA의 이산 토큰 수를 줄이는 별도 방법이다. 세 접근에서 예측 chunk의 길이와 실제 제어 갱신 주기는 공통 비교 축이다.

핵심 설계·학습 신호 해설

저가 하드웨어와 데이터 품질

두 팔의 joint-space mapping은 복잡한 역기구학과 지연을 피하는 설계다. 저가 모터의 토크·정밀도는 한계가 있다. 시스템 비용은 저자의 2023년 추산 약 $18k, 옵션 포함 $20k다.

읽기 포인트가격은 현재 견적이 아니다.

목표 joint와 실측 joint

접촉 시 목표와 실측 사이 오차가 모터 제어에 영향을 준다. 행동을 실측 위치로 잘못 바꾸면 동일한 시연 영상이라도 정책 학습의 의미가 달라진다.

읽기 포인트leader/follower 시계 동기화와 로그를 확인한다.

Chunk와 폐루프

출력 차원은 k×14이고 k=100은 horizon 축소에 유리하지만, 완전 open-loop는 교란에 대응하지 못한다. Temporal ensemble은 서로 다른 관측에서 생성한 예측을 같은 물리 시간에 정렬한다.

읽기 포인트action chunk 예측 길이와 실행 주기를 별도로 보고한다.

CVAE와 추론의 차이

학습 전용 encoder가 시연의 다양성을 설명하고 정책 decoder는 관측과 z를 조건으로 한다. 추론에서는 prior mean을 사용하므로 서로 다른 스타일을 매 순간 섞지 않는다.

읽기 포인트그 자체로 모든 multimodal 성공 경로를 탐색하지 않는다.

05 / 비판적 해석

한계와 비판적 검토

Table I의 scripted/human 비교는 별도 시연 유형의 결과이고 실물은 1 seed/25회여서 높은 성공률의 분산을 판단하기 어렵다. Table II 캡션과 §V-C는 남은 3과제라고 적었지만 실제 4과제 행을 제시한다. 결과는 개별 표의 행을 인용한다. Appendix F의 사탕 포장 풀기는 처음 10회 중 마지막 단계 0회이며, 각 사탕에 10번씩 다시 기회를 주는 별도 protocol에서 5개 중 3개만 성공했다. 납작한 지퍼백을 여는 작업도 후반에 실패했다. 50Hz teleoperation 사용자 연구는 6명, 과제·주파수 순서 무작위, 각 3시행이며 5Hz 명령을 50Hz 보간한 사람 제어 비교이지 ACT의 자체 추론 주파수 ablation이 아니다. 별도 과제마다 처음부터 학습하므로 미지 언어 지시를 이해하는 VLA와 동일하게 보지 않는다. 공개 원본 Figure 3/10은 HTML에서 캡션은 확인했으나 이미지 직접 링크가 없어 사용하지 않고 Figure 5·7·9를 사용한다.

기록할 지표
