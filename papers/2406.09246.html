00 / ONE-MINUTE RECAP

핵심을 먼저 읽기

OpenVLA는 시각·언어 사전학습 표현을 실제 로봇의 7차원 제어로 연결하는 공개 7B VLA다. 중요한 차별점은 단순한 성능 점수가 아니라, 여러 로봇의 시연 데이터로 학습된 공개 가중치와 파인튜닝 가능한 행동 인터페이스라는 점이다. (§1–3)

⌁ DEEP TECHNICAL REVIEW연구자용 상세 해설

읽는 목표: OpenVLA가 LLM 위에 카메라를 붙인 단순 챗봇이 아니라, 행동 좌표를 토큰으로 학습한 제어 정책임을 이해하자. (1) 영상·언어 입력, (2) 시각 특징 정렬, (3) 이산 행동 토큰 생성, (4) 실험 조건이라는 네 구간을 따라가면 PDF Figure 2를 해석할 수 있다. 수치는 논문의 평가 조건과 짝지어 읽는다.

01 / 문제 정의

연구가 풀려는 문제

로봇이 언어 지시와 영상에서 행동을 만들려면, 시각적 의미와 로봇 좌표계의 연속적인 움직임을 함께 다뤄야 한다. 과거 큰 VLA의 가중치가 공개되지 않아 같은 환경에서 실험을 재현하거나 다른 로봇에 적응하는 작업이 어려웠다. OpenVLA는 ‘웹 이미지로 이해하는 능력’과 ‘로봇 시연에서 행동을 예측하는 능력’을 하나의 모델 안에 묶어 이 문제를 풀려고 한다. 단, 공개 여부와 로봇에서의 성공률은 별개의 평가 항목이다. (§1–2)

02 / 핵심 기여

핵심 아이디어

왼쪽 카메라 이미지를 DINOv2와 SigLIP 두 시각 인코더가 서로 다른 관점으로 해석하고, 결합한 특징을 MLP Projector가 언어 토큰 공간으로 투영한다. Llama 2 7B는 이미지와 자연어 목표를 조건으로 ‘다음 단어’ 대신 ‘다음 로봇 행동 토큰’을 예측한다. 로봇이 실제로 실행하는 연속 명령은 마지막에 이산 토큰을 다시 역변환한 것이다. 아키텍처가 PDF Figure 2에 그려져 있다. (§3.1–3.2)

DEEP DIVE / 04

기존 연구와 무엇이 다른가?

Octo는 입력/출력을 교체하기 쉬운 token/readout 정책과 diffusion head에 초점을 맞춘다. OpenVLA는 Llama 2의 다음 토큰 예측을 7D 이산 행동으로 바꾼다. π0는 VLM과 action expert를 분리하고 연속 행동 chunk를 flow matching으로 생성한다. 데이터·평가 로봇이 다르므로 모델 간 숫자 한 줄로 우열을 정하면 안 된다.

03 / 설계와 학습

방법론 · 아키텍처

입력은 관측 이미지 I와 언어 지시 ℓ이다. 이미지 특징을 두 비전 인코더로 계산해 합치고 projector를 거쳐 Llama 2와 정렬한다. 로봇 시연의 7개 행동 차원(위치, 자세, 그리퍼)을 학습 데이터의 각 차원 1~99 백분위 범위로 잘라 256개 구간에 양자화하고, 언어 모델의 드문 토큰 256개를 이 행동 값의 표지로 재활용한다. 네트워크는 행동 토큰을 순차 예측하도록 cross-entropy로 학습한다. 추론은 7개 토큰을 수치로 되돌려 로봇 제어 명령을 구성하는 과정이다. Flow Matching이나 Diffusion을 사용하는 모델과 가장 큰 설계 차이가 여기 있다. (§3.2–3.3)

DEEP DIVE / 01

모델 구조와 처리 흐름

개념적 처리 순서를 정리한 편집 다이어그램이며 원논문의 그림을 복제한 것은 아닙니다.

  1. 01

    1. 이미지와 언어를 받아 상황을 정의

    RGB 관측 I와 ‘컵을 오른쪽으로 옮겨’ 같은 언어 지시 ℓ가 주어진다. 이 입력은 대상 물체와 목표를 정할 뿐, 현재 로봇의 충돌 없는 궤적을 미리 계산하지 않는다.

    Iₜ + instruction ℓ
  2. 02

    2. DINOv2와 SigLIP 비전 인코더 병렬 실행

    동일 영상 패치가 두 시각 인코더를 통과한다. DINOv2는 영상의 일반적인 시각 특징을, SigLIP은 언어와 가까운 시각 의미를 학습한 백본이다. 모델은 특징을 이어 붙여 한쪽만 사용할 때 놓치는 신호를 보완하려 한다.

    [DINOv2(I), SigLIP(I)]
  3. 03

    3. MLP projector로 LLM 입력 임베딩에 정렬

    서로 다른 차원의 이미지 특징을 Llama 2가 언어 토큰과 함께 읽을 수 있는 표현으로 변환한다. Projector 자체가 7차원 로봇 제어를 직접 예측하는 것은 아니다.

    visual features → language-aligned embeddings
  4. 04

    4. Llama 2가 7개 행동 차원용 토큰 예측

    각 연속 행동 차원을 256-bin으로 나누고 언어 모델이 순차적으로 7개 토큰을 생성한다. Loss는 다음 행동 토큰의 분류 cross-entropy이다. 1~99백분위 범위 밖의 값과 정밀 제어에서 양자화 오차가 발생할 수 있다.

    P(a₁,…,a₇ | I,ℓ)
  5. 05

    5. 역토큰화하고 로봇에서 평가

    토큰을 각 차원의 값으로 복구한 뒤 로봇 제어기에 전달한다. 영상·언어 해석과 실제 servo controller, robot-specific action normalization을 혼동하지 말자. 저자는 새 하드웨어에서 LoRA와 양자화 적응도 실험했다.

    discrete bins → 7D action
DEEP DIVE / 02

핵심 설계·학습 신호 해설

Figure 2를 왼쪽에서 오른쪽으로 읽기

영상 입력에서 DINOv2·SigLIP 두 줄을 찾고, 이 특징이 어떻게 합쳐져 MLP로 들어가는지 추적한다. 다음은 Llama 2가 action token을 출력하는 부분이다. 이 그림이 보여주는 것은 정보 흐름이지 새로운 로봇의 성공률 그래프가 아니다.

읽기 포인트그림의 파이프라인과 §3.2의 action discretization을 함께 비교한다.

행동 토큰의 256-bin 양자화

현실의 Δx, Δy, Δz, 방향, 그리퍼 값은 연속 숫자지만, 모델은 사전에 정한 분할 구간으로 바꿔 학습한다. 공통 next-token 학습기법을 재사용하는 장점이 있는 반면, 미세한 접촉이나 집기 위치 보정에 오차가 생길 수 있다.

읽기 포인트행동 차원별 percentile, bin 구성과 예측 토큰 수를 확인한다.

파인튜닝과 LoRA의 평가 범위

작은 로봇 데이터로 정책을 옮길 때 모델 전체를 갱신하지 않고 저랭크 행렬만 학습한다. 사용되는 비전 인코더, 로봇 입력, GPU 자원 및 평가 태스크가 메인 종합 평가와 달라질 수 있으므로, 성공률 수치만 따로 떼어 비교하면 안 된다.

읽기 포인트§5.2–5.4의 베이스라인과 학습 가능 파라미터 조건을 분리한다.
04 / 근거와 결과

실험과 주요 발견

✳

약 970k 실물 로봇 시연을 포함한 Open X-Embodiment 혼합으로 학습했다. 직접 평가에서는 WidowX 17개 과제(방법당 총 170회)와 Google 로봇 12개 과제(방법당 60회)를 합친 29개 과제를 사용한다. 저자는 이 프로토콜에서 RT-2-X보다 평균 성공률이 16.5%p 높았다고 보고한다. 그러나 이 차이는 두 로봇에서 동일하게 발생하지 않으며 작업 종류별 차이가 있다. LoRA 적응 실험은 일부 조건에서 전체 파인튜닝과 비슷한 성능을 더 적은 학습 파라미터로 얻지만, 해당 효율 실험의 백본 설정을 원본 7B 종합 평가와 그대로 동일시할 수 없다. (§5, Appendix B–D)

05 / 비판적 해석

한계와 비판적 검토

이산 256-bin 출력은 연속 행동의 세밀함을 잃을 수 있다. 로봇마다 카메라 위치, 좌표계 및 제어 주기가 달라 단순 가중치 복사만으로 동일한 성능을 보장하지 않는다. 29개 과제의 성공률도 실제 공장·가정·접촉 작업 전부를 대표하지 않는다. 특히 LoRA·양자화의 메모리 효율과 로봇 실환경 성공률은 별도 지표로 봐야 한다. 저자 실험을 독립 재현했다고 주장하지 않는다. (§5–6)

내 연구에 적용한다면?

아래는 논문 저자의 검증 결과가 아니라, 논문에서 출발해 설계한 **후속 실험 제안**입니다.

검증 가설

이산 action token 표현은 정밀한 접촉 제어에서 연속 행동 생성보다 성능 손실이 클 수 있다.

구체적 실험 설계

동일 로봇·동일 RGB/언어 지시·같은 시연 데이터로 tokenized OpenVLA 계열과 연속 행동 생성 계열을 미세조정한다.

비교군·Ablation

256-bin / 128-bin / continuous output, 동일 encoder와 training budget 유지

기록할 지표

task success, 접촉 error, latency, 자원 사용량, perturbation 이후 회복률

실패 해석·주의점

불균등한 데이터 크기나 action normalization 차이가 표현 방식의 효과를 가릴 수 있다.
