Baku: An Efficient Transformer for Multi-Task Policy Learning

Baku는 약 10M 파라미터의 모듈형 모방학습 정책으로 LIBERO-90 90%, 실물 xArm VQ-BeT 91%를 보고한다. 행동 chunking, 관측 history, 모델 크기의 효과를 Table 3에서 분리한다.

00 / ONE-MINUTE RECAP

핵심을 먼저 읽기

적은 시연에서 중요한 것은 파라미터를 무작정 늘리는 것이 아니라 관측 통합과 시간적으로 일관된 행동 출력이다.

01 / 문제 정의

연구가 풀려는 문제

컵을 꺼내기와 오븐 문을 닫기는 같은 카메라와 팔을 사용해도 주목할 위치와 행동의 길이가 다르다. 모든 작업에 거대한 하나의 모델을 적용하면 작업별 데이터가 부족할 수 있고, 독립 단일 작업 정책은 공통 기술을 공유하지 못한다. Baku는 대규모 VLM pretraining 경쟁이 아니라 제한된 전문가 시연에서 다중 작업 BC 설계의 효과를 검토한다.

02 / 핵심 기여

핵심 아이디어

센서 encoder, observation trunk, action head를 분리해 설계 선택을 독립적으로 바꾼다. 텍스트 지시로 FiLM을 조절해 시각 특징을 조건화하고, causal transformer의 action token이 여러 센서를 모은다. 미래 여러 행동을 한 벡터로 출력하고 이전 예측과 시간 평균하여 제어한다. Figure 1의 여러 과제와 Figure 2의 행동 chunk를 비교하면 명령이 어떻게 행동으로 연결되는지 보인다.

DEEP DIVE / 04

기존 연구와 무엇이 다른가?

RT-1의 균일 이산화 행동과 MT-ACT의 encoder-decoder 대비 Baku는 modality trunk 및 독립 action head를 단순화한다. 2024년의 동일 실험 비교를 2026년 VLA와 직접 순위 비교하지 않는다. 원문 Table 1과 §4.2의 실물 과제 수 불일치를 그대로 밝힌다.

DEEP DIVE / 02

핵심 설계·학습 신호 해설

FiLM은 왜 필요한가

동일한 장면이라도 '오븐 문 닫기'와 '접시 들기'는 다른 시각 특징을 요구한다. 지시에서 만든 scale/shift로 시각 encoder의 특징을 조절한다. LIBERO 87→90%지만 Meta-World는 79%로 동일하다.

읽기 포인트Appendix A.1; Table 3

action token과 감각 융합

MLP trunk는 연결된 특징을 입력받고 transformer는 각 센서 토큰과 action token을 처리한다. 같은 비교에서 LIBERO 81→90%로 향상되지만 DMC 68→70%로 작다.

읽기 포인트§3.2, Table 3

Action chunk와 history 차이

chunk는 미래 여러 행동 출력, history는 과거 여러 관측 입력이다. 전자가 LIBERO 76→90%를 올리지만 DMC 74→70%로 낮춘다. history last-step-only loss는 54%로 감소하고 multi-step loss는 90% 회복한다.

읽기 포인트Table 3

큰 모델 반례

LIBERO 4.4M=85%, 10M=90%, 31M=87%, 114M=19%. 데이터가 적을 때 큰 모델 성능이 나빠질 수 있으나 모든 benchmark에서 같은 추세는 아니다.

읽기 포인트Table 3

Head 선택의 상호작용

시뮬 Meta-World의 MLP 79% vs diffusion 45%인 반면 실물 VQ-BeT가 MLP 86%에서 91%로 향상된다. 동일 trunk라 해도 행동 분포와 데이터 규모에 따라 달라진다.

읽기 포인트Table 1·3

훈련 비용

05 / 비판적 해석

한계와 비판적 검토

단일 실물 xArm 주방과 정해진 평가 위치에 기반한다. 보지 못한 작업에 대한 zero-shot VLA 성능은 입증하지 않는다. DMC는 영상이 아닌 상태 입력으로 평가되어 조작과 직접 평균하기 어렵다. 긴 작업은 두 단계 연결 중심이며 대규모 장기 계획 능력 일반화가 아니다.

비교군·Ablation

MLP/transformer trunk, chunk 1/10, history no/last/multi, FiLM off/on, MLP/VQ-BeT head를 한 번에 하나씩 바꾼다.

기록할 지표

성공률과 task별 CI, 행동 jerk, 추론 p95, 학습시간, GPU memory, 장기과제 완수율.

실패 해석·주의점

실물 평가 과제 명단과 시행 횟수를 명시해 원문의 20/30 표기 차이를 해결하고 평가에서 시연 위치 중첩을 보고한다.
