ScaleVLA: Scaling Vision-Language-Action Models to 552 Billion Parameters

552B MoE 기반 VLM의 일부 표현만 추출해 행동 DiT에 연결하는 ScaleVLA를 분석한다. 같은 행동 학습 조건에서 LIBERO 96.1%, LIBERO-PRO 45.1%를 보고했지만, 추론에는 H200 4장이 필요하며 실물 충전기 삽입 시험은 제한된 횟수다.

00 / ONE-MINUTE RECAP

핵심을 먼저 읽기

연구 질문은 '더 큰 언어모델이 로봇에 얼마나 유용한가'가 아니라 같은 행동 전문가·데이터·학습 예산으로 VLM 표현만 크게 바꾸면, 적은 시연과 분포 이동 및 정밀 접촉에서 무엇이 달라지는가이다. ScaleVLA의 장점은 단순 백본 크기보다 얼어 있는 552B MoE의 인코더 특징을 짧은 행동 생성 루프로 재사용하는 인터페이스에 있다.

01 / 문제 정의

연구가 풀려는 문제

종래의 많은 VLA는 2B–32B급 시각언어모델과 학습 가능한 행동 헤드를 결합한다. 평범한 컵 집기에서는 작은 모델도 높은 성공률을 내므로, 더 큰 모델을 채택할 이유가 불분명하다. 그러나 '충전기 플러그를 소켓 구멍에 맞춰 끼우기'에서는 대상의 의미를 아는 것과 작은 자세 오차를 피하며 손을 움직이는 것이 다르다. 저자들은 규모만 변경한 비교군으로 시연 5–50개인 저자원 학습, 교란된 LIBERO-PRO, 실제 양팔 충전기 삽입을 평가한다. 이것은 552B 모델이 새로 로봇 동작을 학습했다는 의미가 아니다(§1–2).

02 / 핵심 기여

핵심 아이디어

전체 552B를 로봇 제어용으로 미세조정하거나 매 tick 텍스트 추론을 생성하지 않는다. 동결된 DeepSeek-V4.1-Flash-1017의 시각·지시 조건 인코더가 만든 특징을 별도 adapter와 trainable action diffusion transformer(DiT)에 넣고, 연속 행동 청크의 속도장을 예측한다. 비유하면 전문가가 쓴 복잡한 환경 해석을 '행동 지시용 특징'으로 읽고, 손을 움직이는 소규모 전용 제어기를 따로 학습한다. 여러 작은 백본에 같은 action-side 설계를 적용해 표현 규모의 효과를 비교한다(Figure 2).

DEEP DIVE / 04

기존 연구와 무엇이 다른가?

π0/GR00T류 VLA가 다중 모달 인식기와 행동 생성기를 붙인다는 점은 새롭지 않다. 여기서 핵심 통제변수는 가능한 동일한 행동 헤드·데이터·학습 예산을 유지한 채 VLM 표현 크기를 2B–552B로 바꾸는 것이다. 단순 LIBERO 평균만 보면 96.1% 대 94.0% 차이로 작아 보여도, Goal 10-shot과 LIBERO-PRO 같은 데이터 부족/분포 이동에서 격차가 커진다. 하지만 비교에서는 MoE sparse execution, 서로 다른 GPU 장수, 로봇 작업 데이터와 사전학습 정보가 서로 얽혀 있어 '파라미터 수만의 인과 효과'로 단정할 수 없다.

03 / 설계와 학습

방법론 · 아키텍처

§3와 Appendix A의 입력은 외부 카메라 이미지·언어 지시·로봇 상태다. DeepSeek VLM은 동결돼 있고 디코더를 통한 자기회귀 답변 생성 없이 20층 causal encoder의 표현을 사용한다. 5120차원 특징을 2048차원으로 사상하는 adapter(4층 transformer)를 거친다. 로봇별 상태/행동 인코더와 32층 action DiT가 비디오 및 비비디오 토큰의 자기·교차 attention을 교대로 처리한다. 행동 A와 Gaussian 잡음 ε를 섞은 중간 상태 Aτ=(1−τ)ε+τA에서 목표 속도 A−ε를 회귀하는 flow matching을 학습하며, 배포 시 4단계 적분으로 행동 청크를 만든다. LIBERO는 16-step 출력 가운데 8-step을 실행하는 식으로 재계획하고, 특징 계산을 청크 단위로 캐시한다. 백본 파라미터 전체가 업데이트되는 end-to-end VLA라고 부르면 오류다.

DEEP DIVE / 01

모델 구조와 처리 흐름

개념적 처리 순서를 정리한 편집 다이어그램이며 원논문의 그림을 복제한 것은 아닙니다.

  1. 01

    01 | 영상·언어 지시와 로봇 상태 분리

    카메라 관측/텍스트 지시를 동결된 VLM으로 보내고, 관절·그리퍼 등 embodiment-specific state는 별도 인코더로 통과시킨다. 언어모델에게 '다음 행동'에 대한 긴 텍스트를 쓰라고 하지 않는다.

    RGB + instruction → VLM features; state → state embedding
  2. 02

    02 | 거대한 MoE의 부분 연산만 호출

    DeepSeek-V4.1-Flash-1017 전체 모델은 552B 파라미터지만 sparse expert를 활성화하며, 동결된 causal encoder 20층의 출력을 읽고 언어 디코더 생성은 생략한다. 스케일 자체와 실 실행 compute를 구분해야 한다.

    frozen causal features, dimension 5120
  3. 03

    03 | 행동 조건 adapter 압축

    VLM 5120차원 표현을 2048차원으로 바꾸고 4-layer adapter transformer가 행동 생성기에 적합한 조건 시퀀스를 만든다. 로봇별 state/action projector가 형태가 다른 기구의 joint 벡터를 매개한다.

    5120 → 2048, 4-layer adapter
  4. 04

    04 | 32층 행동 DiT의 교차 정보 교환

    행동 노이즈 token은 상태와 VLM 조건의 주의를 받으면서 32층 action DiT에서 갱신된다. 이미지·텍스트 특징을 그대로 motor command로 쓰는 구조가 아니라 시간적 action chunk를 생성한다.

    conditional action DiT, 32 layers
  5. 05

    05 | flow matching으로 미래 행동 생성

    정답 시연 청크 A와 가우시안 ε로 Aτ=(1−τ)ε+τA를 만들고 모델이 A−ε라는 이동 속도장을 맞히게 한다. 추론에는 네 번의 수치적 흐름 적분으로 노이즈를 행동으로 변환한다.

    velocity regression → 4 flow steps
  6. 06

    06 | 청크 실행·평가 프로토콜

    LIBERO는 16-step prediction 중 8-step을 적용하는 폐루프이며, RoboCasa는 720-step 한도/24 테스트 task/50 episodes, 실제 양팔은 plug-in 성공과 완료 시간도 기록한다. 이미지 특징 캐싱과 action chunk별 지연을 분리한다.

    action chunk → execute/re-observe; 4×H200 latency setting

핵심 설계·학습 신호 해설

훈련에서 실제로 바뀌는 파라미터

동결된 552B 백본은 외부 지식 저장소처럼 동작한다. 학습은 주로 adapter·state/action projector·행동 DiT에 집중한다. pretrained control head를 가져온 결과와 혼동하지 않으려는 비교 설계다.

4-step 생성이 autoregressive reasoning과 다른 이유

04 / 근거와 결과

실험과 주요 발견

✳

동일 저자 재학습 조건의 LIBERO 4-suite 평균은 ScaleVLA 96.1%, Cosmos-Reason2 2B 90.7%, Cosmos 32B 94.0%(Table 2). 훈련 장면의 환경·물체를 교란한 LIBERO-PRO 평균은 45.1%로 더 어렵고, 비교군 최고 31.3%보다 높지만 여전히 절반 이하가 실패한다(Table 3). LIBERO Goal의 10 demonstrations/task는 87.8%, 2B의 50 demos/task는 85.6%지만 Appendix D의 저데이터 실험은 full-set normalization 통계를 사용한다. 실물 양팔 Plug In Charger 성공은 in-domain 9/10, OOD 8/15회이며, 이는 같은 데모와 행동 head 조건의 2B 모델 4/10, 5/15보다 높다(Table 8). RoboCasa 청크 지연 215.8ms는 H200 네 장, Cosmos2B 114.7ms는 H200 한 장이므로 동일 하드웨어 지연 비교로 해석하면 안 된다(Table 6).

05 / 비판적 해석

한계와 비판적 검토

MoE 전체 552B 규모는 활성 파라미터/메모리/분산 추론 비용과 동일하지 않다. 4×H200 배치와 1×H200 배치의 지연 및 총비용 비교는 별개이고, 청크당 중앙값은 실제 모터 closed-loop 95백분위 지연을 보증하지 않는다. 실물 실험은 단일 plug 과제 10+15회/정책 및 훈련 seed 제약이 있어 광범위한 양팔 일반화 증거가 아니다. LIBERO 만점에 가까운 점수는 ceiling effect가 크고 LIBERO-PRO는 45.1%로 아직 취약하다. 저시연 수 비교에서 전체 데이터의 정규화 통계를 활용하는 Appendix 단서는 완전 무정보 10-shot 설정과 다르다. Figure 5는 저자 선택 사례이며 전체 실패 분포를 대체하지 않는다.
