Nexus-VLA: Bridging Human and Robot Experiences via a Shared Hierarchical Semantic Latent Space

사람의 1인칭 조작 영상에 로봇 관절 명령이 없더라도 작업 의도·공간 목표·손의 이동·접촉을 계층적 의미 잠재공간에서 정렬하면 로봇 행동 정책에 도움이 될까요? Nexus-VLA는 인간 21,446개 영상과 로봇 24,000개 시연을 공동학습해 RoboCasa-GR1 24과제 성공률 80.5%를 보고합니다. 공동학습과 계층적 감독의 효과를 구분하고 실물·OOD 수치의 분모를 확인합니다.

00 / ONE-MINUTE RECAP

핵심을 먼저 읽기

사람과 로봇의 동작 좌표를 억지로 일치시키는 대신, 작업의 단계와 접촉 의미를 하나의 잠재표현으로 묶어 실제 로봇의 연속 동작 생성 손실과 연결하는 것이 핵심입니다. (§3, Fig.2)

⌁ DEEP TECHNICAL REVIEW연구자용 상세 해설

독해 핵심: Nexus-VLA는 사람의 손 궤적을 그대로 로봇 관절에 역운동학으로 옮기는 연구가 아닙니다. 인간·로봇 데이터에서 공유되는 작업 의미를 z_sem에 학습시키고, 이 표현을 실제 조건부 행동 생성에 집어넣습니다. 수치는 논문 Tables 1–4와 Appendix의 서로 다른 평가 범위를 먼저 분리해 읽어야 합니다.

01 / 문제 정의

연구가 풀려는 문제

사람의 POV 영상에는 손으로 컵을 집는 장면이 담기지만 로봇 관절각·그리퍼 열림값은 없습니다. 사람 영상으로 단순 VLM을 사전학습하고 로봇 정책을 별도로 학습하면 시각 특징이 행동에 정말 필요한지 최종 손실이 피드백하지 못합니다. 반대로 사람 손목 경로를 로봇 관절 명령으로 바로 복제하면 embodiment·카메라 좌표계와 접촉점이 달라질 때 실패합니다. 이 논문의 질문은 인간 경험에서 공유할 수 있는 '무엇을 어떻게 옮기는가'라는 의미를 로봇 행동의 학습 신호로 바꾸는 방법입니다. (§1–3)

02 / 핵심 기여

핵심 아이디어

직관적으로 사람이 머그컵을 선반에 올리는 영상을 볼 때 로봇에게 중요한 것은 사람 손가락의 각도 자체보다 '컵 선택→목표 선반 식별→손목 이동→접촉·해제'입니다. Nexus-VLA는 하나의 semantic token에 거친 의도, 2D 공간 목표, 손목 이동, 상호작용 상태를 함께 담도록 학습하고, 해당 토큰 표현을 로봇용 행동 diffusion 조건으로 사용합니다. 의미 라벨은 학습 때만 사용하는 보조 감독이며 추론 때 매번 네 가지 문구를 언어로 출력하는 시스템이 아닙니다. (Fig.1–2, §3)

DEEP DIVE / 04

기존 연구와 무엇이 다른가?

로봇 전용 imitation learning은 명확한 관절 행동 레이블을 쓰지만 사람 영상 확장성은 제한됩니다. Human-video representation을 따로 학습해 freeze하는 방법은 이미지 표현을 전이하되 제어 손실이 의미 표현을 거꾸로 최적화하기 어렵습니다. Nexus-VLA는 semantic token에 네 종류 감독→joint+wrist 분리 및 mask→DiT flow matching을 하나의 공동학습 경로에 넣습니다. 이것은 human-motion retargeting을 완전히 해결했다는 주장이 아니라, robot-specific controller 안에 human semantic signal을 주입한다는 주장을 검증하는 설계입니다.

03 / 설계와 학습

방법론 · 아키텍처

시각언어 백본 Qwen2.5-VL-3B의 입력에 learnable semantic token을 추가하고 인과 self-attention 후 hidden state z_sem을 읽습니다. 네 종류 Structured Manipulation Expert가 학습용 의사 감독을 제공합니다: Intent는 로컬 subtask, Spatial은 조작 물체·목표의 2D box, Motion은 미래 양손/손목 2D 궤적, Interaction은 손·물체 접촉점/상태입니다. 각 supervision은 별도 projection head를 통해 단일 z_sem을 훈련시킵니다. 사람 데이터는 로봇 관절 label이 없으므로 action을 [robot-specific joint, shared wrist]로 나누고 사람 샘플에서는 joint 부분을 mask합니다. 로봇 시연은 두 부분을 모두 학습시키고 DiT 연속 행동 head가 16-step action chunk를 flow matching으로 학습·추론합니다. 인간:로봇 혼합비는 1:2이며 별도 라벨 추론이 실행 시 필요하지 않습니다. (§3 및 Appendix A–B)

DEEP DIVE / 01

모델 구조와 처리 흐름

개념적 처리 순서를 정리한 편집 다이어그램이며 원논문의 그림을 복제한 것은 아닙니다.

  1. 01

    01. 서로 다른 두 데이터의 관측을 구성

    RoboCasa-GR1 24과제 로봇 시연 약 24,000개와 EgoDex에서 필터링한 사람의 egocentric 영상 21,446개를 섞습니다. 짝지어진 동일 작업 인간–로봇 촬영본이 아니라 서로 다른 도메인에 존재하는 관찰·행동 신호입니다.

    RGB + 언어 지시 + (로봇만) 관절·동작
  2. 02

    02. Semantic token이 사전학습 VLM에서 의미를 읽음

    Qwen2.5-VL-3B가 이미지/언어 토큰을 처리할 때 학습 가능한 semantic token을 추가합니다. 마지막 semantic 위치의 hidden representation z_sem이 후속 의미 정렬과 행동 생성의 공통 인터페이스가 됩니다.

    (visual, language, semantic token) → z_sem
  3. 03

    03. Intent·Spatial·Motion·Interaction 네 감독

    학습에서만 네 전문 모델이 pseudo semantic target을 만듭니다. Intent는 현재 소과제, Spatial은 원천/목표 bounding box, Motion은 미래 손목 2D 궤적, Interaction은 손과 물체의 접촉점·접촉 상태를 제공합니다. 개별 projection head에 가해지는 손실이 공유 z_sem을 조정합니다.

    z_sem → 4 auxiliary losses; 지도는 추론에서 생략
  4. 04

    04. Embodiment mask로 사람과 로봇 행동 감독을 구분

    행동 표현의 로봇 고유 joint 부분과 공통 wrist 부분을 분리합니다. 인간 샘플은 관절 지시가 없으므로 joint loss를 mask하고, 로봇 샘플은 둘 다 학습합니다. 사람의 손동작을 로봇 관절과 동일시하지 않는 핵심 장치입니다.

    [joint,wrist] action + per-domain supervision mask
  5. 05

    05. DiT flow matching으로 연속 행동 chunk 생성

    z_sem과 로봇 관측을 조건으로 action DiT가 길이 16의 연속 행동을 생성하도록 학습합니다. 추론에서는 이미지·언어→z_sem→DiT action 순서이며, 학습용 의사감독 모델과 사람별 관절 추정기는 추가로 실행하지 않습니다.

    image+instruction → z_sem → 16-step robot action
DEEP DIVE / 02

핵심 설계·학습 신호 해설

왜 네 개 의미 target을 하나의 latent에 몰아넣는가?

소과제 의도만 잘 맞혀도 실제 그립 접촉 시점은 놓칠 수 있습니다. 물체 box·손목 궤적·접촉 정보를 동시에 감독해 복수 시간척도를 공유 표현에 강제하는 것입니다. 다만 잠재 차원에 과부하가 생길 수 있어 독립 head와 unified latent의 비교(Table3)가 중요합니다.

읽기 포인트ablation에서 independent latents 76.92% vs unified 78.25%가 같은 설정인지 확인합니다.

사람 영상과 로봇 action의 손실을 왜 마스킹하는가?

사람 영상에는 로봇 관절 action target이 없는데 이를 0벡터 정답으로 학습시키면 정책에 잘못된 행동을 강화할 수 있습니다. joint channel은 robot-only로 감독하고 wrist channel을 공유하면 사람의 공간적 움직임을 이용하면서 로봇 특유의 구동 제약은 정책에서 유지할 수 있습니다.

읽기 포인트mask 적용 위치와 observation-to-wrist coordinate 차이는 별도로 평가해야 합니다.

학습 프로토콜이 다른 성공률을 섞지 않기

Table1의 80.5%는 24과제 종합 비교, Table3의 80.17%는 공동학습 구조의 ablation, Table2의 68.9%는 OOD 6개 설정 평균, 실물 74%는 여러 테스트 조건 평균입니다. 정확도 범위가 다르기 때문에 단일 수치로 대체할 수 없습니다.

읽기 포인트분모(rollouts, tasks, settings)·훈련 스텝·선정 체크포인트를 함께 표기합니다.

실환경 성능을 과대 일반화하지 않기

표준 실제 환경 82%에서 unseen object 68%로 떨어지는 것은 학습된 잠재공간이 일반화 이득을 제공하더라도 물체 형태·시점 분포 이동에 취약함을 보여줍니다. Figure 1은 정성적 파이프라인, Figure 2는 메커니즘 구조이지 그 자체가 성공률의 증거가 아닙니다.

읽기 포인트Appendix 작업별 분산 및 실패 사례를 함께 검토합니다.

05 / 비판적 해석

한계와 비판적 검토

Nexus의 개선이 학습 데이터 양의 증가, 계층 감독, 디코더/백본, 학습 비용 중 어디서 얼마나 비롯됐는지 단일 벤치마크 평균으로 완벽히 분해할 수는 없습니다. 사람 손목의 2D 이미지 좌표와 실제 로봇의 3D 제어·접촉 정보 사이의 카메라 보정과 스케일 차이는 근본 난점입니다. 24개의 모의 주방 과제와 선택된 실제 6과제는 무한한 실제 환경의 범위를 보증하지 않습니다. Appendix의 개별 작업에서는 Nexus가 항상 최고가 아니며, PlateToPan과 PlateToPlate 등의 하위 사례를 함께 봐야 합니다. 공식 arXiv PDF/HTML의 이번 실행 직접 접근이 제한된 점도 이 글의 근거 범위에 명시합니다.

RESEARCH LAB / EDITORIAL PROPOSAL

내 연구에 적용한다면?

아래는 논문 저자의 검증 결과가 아니라, 논문에서 출발해 설계한 **후속 실험 제안**입니다.

검증 가설

의도/접촉 중심의 통합 표현을 DiT 행동 손실과 공동학습하면 단순 human video concat 또는 frozen human encoder보다 적은 로봇 시연에서도 OOD task 성공률이 높아질 것입니다.

구체적 실험 설계

RoboCasa-GR1 8개 고정 과제, 동일 Qwen2.5-VL와 동일 DiT를 사용합니다. 로봇 시연 25/50/100%와 사람 영상 0/5k/20k를 교차하고, 모든 조건에서 동일 로봇 gradient update·seed 5개를 사용합니다.

비교군·Ablation

Robot-only, raw human video mixture(no semantic losses), frozen semantic encoder, four-independent latents, unified latent without interaction, full model; backbone/action steps/GPU budget control.

기록할 지표

Strict task success(각 작업 100 attempts), 6종 OOD 분리 성공률, 미관측 물체 category별 혼동, contact timing error, GPU-hour 및 데이터 라벨 생성 비용.

실패 해석·주의점

생성된 pseudo labels의 오류, 평가 로봇 카메라 캘리브레이션 차이, human-vs-test task semantic overlap이 인간 데이터의 이득을 과장할 수 있습니다.
