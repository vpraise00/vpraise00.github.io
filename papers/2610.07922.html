01 / 문제 정의

연구가 풀려는 문제

WAM 논문들은 비디오 예측 모델, 행동 정책, 학습 감독, 추론 순서를 한꺼번에 바꾸는 일이 많아 무엇이 성능에 기여했는지 비교하기 어렵습니다. 동일 기반에서 결합 방식만 바꾸는 실험장이 필요합니다.

02 / 핵심 기여

핵심 아이디어

공통 인과적 로봇 비디오 모델 위에 action expert를 붙이고, 비디오-행동 동시 생성, 비디오 선행, 행동 선행, 분리 생성 등을 공통 프레임에서 비교하도록 만듭니다.

03 / 설계와 학습

방법론 · 아키텍처

Wan2.2-5B에서 시작해 1만 시간 이상의 로봇 비디오로 causal pretraining을 수행합니다. Shared Mixture-of-Transformers 구성에서 비디오 생성과 행동 생성을 조합하고, inverse/forward dynamics 및 반사실적(counterfactual) 전이를 분석합니다.

04 / 근거와 결과

실험과 주요 발견

✳

초록은 LIBERO-Long의 VTA 성공률이 causal video 학습 후 68.4%에서 97.8%로 상승했다고 보고합니다. 별도 held-out LIBERO-90 네 과제에서 counterfactual 학습을 쓴 local-context inverse dynamics가 평균 84.0% 성공률을 보인다고 설명합니다.

05 / 비판적 해석

한계와 비판적 검토

비디오 생성의 계산비용과 지연시간이 실제 하드웨어 배치에 중요한 변수입니다. 1만 시간 이상의 비디오·대형 백본 사용은 소형 연구실의 재현 부담을 높일 수 있습니다.

⌁ DEEP TECHNICAL REVIEW연구자용 상세 해설

OpenWAM은 “video predictor + action expert를 같이 쓰면 좋아진다”에서 끝나지 않고, 둘의 생성 순서를 바꿔가며 검증할 수 있는 공통 실험 플랫폼을 제시한다. 로봇 비디오용 causal backbone, MoT 결합, VTA/JOIN 등의 추론 프로그램을 같은 토대 위에 올리고, counterfactual dynamics를 통해 시연 밖의 상태 전이까지 학습하는 효과를 비교한다.

DEEP DIVE / 01

모델 구조와 처리 흐름

개념적 처리 순서를 정리한 편집 다이어그램이며 원논문의 그림을 복제한 것은 아닙니다.

  1. 01

    로봇 비디오 기반 사전학습

    Wan2.2-5B에서 출발해 다양한 로봇·인간·합성 상호작용 영상으로 causal robot-video pretraining을 수행한다. 이 단계의 핵심 supervision은 action label이 아니라 관찰 영상의 시간적 구조다.

    입력: 1만 시간 이상 영상 / 로봇 동작 동역학의 시각 특징
  2. 02

    비디오 expert + action expert 구성

    5B video stream과 약 2B action expert를 Mixture-of-Transformers 구조로 결합하고, 필요한 지점에서 두 종류의 토큰이 정보를 주고받게 한다.

    구성: shared attention, expert-specific blocks
  3. 03

    생성 프로그램 바꾸기

    joint 생성 / video→action / action→video / decoupled 등 서로 다른 영상·동작 인터랙션을 지원한다. 특정 방식에서 성능이 높아도 다른 방식에는 적용되지 않을 수 있다.

    제어: composable video-action schedules
  4. 04

    역·순방향 동역학 학습

    inverse dynamics는 상태 변화에서 action을, forward dynamics는 action에서 미래 변화를 추정한다. demonstration 외의 counterfactual transition도 supervision으로 사용한다.

    출력: behavior policy 또는 reusable dynamics
  5. 05

    제한된 타깃 작업으로 전이

    미래 영상 예측기만 작업에 맞춰 적응하고, 독립적으로 학습한 inverse dynamics를 재사용하는 구성을 실험한다.

    평가: held-out task transfer
DEEP DIVE / 02

핵심 설계·학습 신호 해설

왜 Causal Video Pretraining인가

일반 비디오 모델의 대칭적 시간 처리가 실제 robot closed-loop inference와 맞지 않을 수 있다. 과거와 현재만으로 미래 chunk를 생성하도록 설계를 바꾸고 로봇 상호작용 분포에 맞춰 학습한다.

읽기 포인트pretrain 데이터 크기뿐 아니라 causal adaptation 유무를 별도 ablation으로 읽자.

Shared Mixture-of-Transformers

시각적 프레임 생성과 연속 행동 예측은 출력 차원·목적함수가 다르다. 하나의 trunk로 억지 통합하기보다 토큰 간 attention 경로는 공유하면서 video/action expert의 전용 파라미터를 보존한다.

읽기 포인트MoT 개선 폭은 같은 pretraining, 같은 train data에서 측정된 것이어야 한다.

Counterfactual Dynamics의 가치

성공 시연에는 특정 상태에서 실제 선택된 action 결과만 존재한다. 여러 다른 action을 취했을 때의 결과(counterfactual)를 학습하면 inverse/forward 모델이 관측 영상에 과적합하는 문제를 줄일 수 있다.

읽기 포인트counterfactual 데이터가 실제 궤적과 얼마나 물리적으로 타당한지 확인할 것.

Local-context IDM 전이

새 작업의 영상 생성기는 바꾸되, 짧은 시간 창만 보는 inverse dynamics를 동결해 행동을 회복한다. 긴 전체 문맥을 보게 하는 모델보다 국소 동역학의 이식성이 높을 수 있다는 가설이다.

읽기 포인트task-specific retraining 없이 unseen scene/action 분포에서 성립하는지 중요하다.

DEEP DIVE / 04

기존 연구와 무엇이 다른가?

일부 WAM 연구는 pretraining 규모·비디오 백본·action decoder·조건부 생성 순서를 동시에 바꾼다. OpenWAM은 이를 구성 가능한 프로그램으로 나눠 같은 비디오 파운데이션 위에서 원인을 분해하려는 점이 가치다. SG-WAM이 정책 latent의 alignment를 연구한다면 OpenWAM은 비디오와 행동을 결합하는 시스템 설계 공간을 연구한다.

DEEP DIVE / 05

원문을 읽으면서 확인할 4가지

  1. 영상 사전학습 자료 구성(로봇/인간/합성 비중)과 causal attention 설계가 초기화 개선 폭에 얼마나 기여했는지 분리하기.
  2. VTA, Joint, ATV, decoupled의 token-visible 구조와 샘플링 순서를 그림으로 다시 그리기.
  3. LIBERO-Long 비교의 action frequency, denoising 횟수, 예측 horizon, 로봇 observation frame 수 확인하기.
  4. counterfactual IDM의 frozen setting이 다른 작업·카메라·로봇 embodiment에서 유지되는지 찾아보기.
  5. 가용 GPU 수와 학습시간을 포함한 재현 가능성을 판단하기. 대규모 비디오 단계의 비용은 별도다.
RESEARCH LAB / EDITORIAL PROPOSAL

내 연구에 적용한다면?

아래는 논문 저자의 검증 결과가 아니라, 논문에서 출발해 설계한 **후속 실험 제안**입니다.

검증 가설

정책 학습 성능에서 로봇 비디오 causal pretraining과 video-action 결합 순서의 효과를 독립적으로 확인할 수 있다.

구체적 실험 설계

기존 공개 video backbone과 소형 action head를 사용해 동일 LIBERO task subset에서 2×3 factor experiment(비디오 pretraining 유무 × Joint/VTA/decoupled) 수행.

비교군·Ablation

영상 없는 VLA, raw Wan initialization, robot-video pretrained initialization, MoT vs shared-head. 가능한 한 총 학습 토큰·fine-tune 데이터량을 맞춘다.

기록할 지표

success %, video prediction quality, inverse dynamics action error, control latency, GPU-hour, failure recovery.

실패 해석·주의점

모델 크기·pretraining data 차이를 통제하지 않으면 interaction 방식 자체의 효과가 과장될 수 있다.
