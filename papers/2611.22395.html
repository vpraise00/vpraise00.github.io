CoBoVLA: Decoupling Language from Action with Discrete Codes for Robust and Interpretable Robot Manipulation

6슬롯 의미 코드와 MDL 동작 코드로 언어 이해·행동 계획·제어를 분리한 250.3M VLA. LIBERO-Goal 91.4%, LIBERO-Para 81.1%, 2-step 78/160; 다중 지시 실패와 초기상태 중첩·평가 조건까지 분석했다.

00 / ONE-MINUTE RECAP

핵심을 먼저 읽기

언어를 모터 제어기에서 분리하면 실패 원인이 보인다. 동의 문장들이 같은 6슬롯 step-code가 되면 planner는 목표 단어 없이 동작 코드를 선택할 수 있다. 단어 해석이 틀렸는지 모션 실행이 틀렸는지 코드별로 읽는 것이 CoBoVLA의 핵심이다(§3·Figure 2).

⌁ DEEP TECHNICAL REVIEW연구자용 상세 해설

해설의 분리 기준: 원논문 Figure 2(b)의 meaning codebook과 (c)의 action-code MDL 분절은 입력 데이터와 감독 신호가 완전히 다르다. 이 차이를 놓치면 '텍스트만 학습해서 새로운 동작을 생성한다'는 오해가 생긴다. Table 1/2/4 및 Appendix S5의 평가 횟수도 섞어서는 안 된다.

01 / 문제 정의

연구가 풀려는 문제

LIBERO의 canonical 지시문을 학습한 VLA는 '그릇을 찬장 위에 올려라'를 비슷한 뜻의 '그릇을 사이드보드 위에 놓아줘'로 바꾸면 다른 물체와 목표를 선택할 수 있다. 0.6B–7.5B 모델도 LIBERO-Para에서 성공률 하락을 보였고 전형적인 end-to-end 정책은 언어 이해 실패와 제어 실패를 내부적으로 분리해 관찰하기 어렵다. 제어 주기마다 언어와 영상을 함께 처리하는 비용도 크다.

02 / 핵심 기여

핵심 아이디어

독립된 두 종류의 이산 인터페이스를 만든다. 텍스트 encoder는 지시의 각 단계를 여섯 개 의미 슬롯(각 32개 중 하나)으로 표현하고, 다른 단어로 말해도 같은 의미 코드를 내도록 텍스트 쌍만으로 학습한다. 모션 시연은 MDL 가변 길이 분절을 통해 두 레벨 action code로 압축한다. 시각 planner는 step code와 이미지/상태에서 다음 action code chain을 예측하고 actor는 language를 직접 보지 않고 flow-matching 행동을 출력한다. Figure 1은 성공/실패 단일 예시, Figure 2는 실제 아키텍처·학습 경로다.

DEEP DIVE / 04

기존 연구와 무엇이 다른가?

기존 SmolVLA·π0처럼 언어/행동을 한 모델에 결합하면 동의 문장 변형의 원인을 찾기 어렵다. CoBoVLA는 의미 인터페이스를 텍스트 데이터로만 바꿔도 downstream motion actor를 건드리지 않는 장점을 가진다. 다만 코드가 맞았다고 조작 성공이 자동 보장되지 않으며, MDL 코드의 해석 가능성은 통계적 의미다. Appendix E는 gripper 이벤트 분할보다 재사용이 높아도 task 판별 성능은 낮을 수 있음을 보여준다.

03 / 설계와 학습

방법론 · 아키텍처

훈련 순서는 ① 1,693개 LIBERO 시연을 residual VQ(레벨당 32)로 인코딩하고 MDL 동적 계획법으로 6–192step segment를 찾는 8라운드 과정, ② bge-base 6슬롯 의미 codebook에 paraphrase 양방향 코드 예측/언어 reconstruction·commitment·entropy·중복 방지 적용, ③ 소형 bge-small step coder(38.4M)를 최대 세 지시 단계에 맞춰 학습, ④ 공유 frozen SigLIP 86.4M에서 전면/손목 카메라를 읽는 26.1M planner가 3개 행동 segment를 예측, ⑤ 99.4M actor가 모션 코드와 영상을 조건으로 flow matching 연속 행동 chunk를 생성하는 단계다. 총 250.3M은 actor 고유 SigLIP tail 사본도 포함한다(Appendix A). 추론 때 사용자 문장은 처음 한 번만 인코딩되며 actor는 단어 자체를 보지 않는다.

DEEP DIVE / 01

모델 구조와 처리 흐름

개념적 처리 순서를 정리한 편집 다이어그램이며 원논문의 그림을 복제한 것은 아닙니다.

  1. 01

    MDL 동작 분절과 코드북

    1,693개 LIBERO 시연 행동을 6–192 제어스텝 길이 가변 세그먼트로 분할한다. 2레벨·각 32개 residual VQ로 재구성 비용과 구간 길이/코드 빈도 비용을 함께 최소화한다. 초기 16-step 구간에서 시작해 8회 동적계획법 분할과 autoencoder 재학습을 반복한다.

    demonstration actions → segmentation → 2×32 codes
  2. 02

    언어 쌍으로 의미 코드북 학습

    bge-base와 여섯 의미 슬롯, 공유 K=32 cosine codebook. 같은 작업의 다른 패러프레이즈가 같은 코드로 상호예측되도록 학습하고 언어 재구성·commitment·entropy·slot중복 방지 손실을 결합한다.

    paraphrases only → 6 discrete semantic slots
  3. 03

    경량 step coder 학습

    bge-small 일부 층만 미세조정해 사용자 문장을 최대 3개 하위 지시로 분리하고 각 단계의 여섯 슬롯 의미 코드를 예측한다. 배포 모델의 step coder는 38.4M 매개변수.

    instruction → z_step^1,...,z_step^S
  4. 04

    시각 planner의 다음 모션 구간 선택

    전면·손목 카메라의 공유 frozen SigLIP 토큰과 8차원 robot state, 현재 의미 코드를 받아 26.1M planner가 이후 세 action-code segment와 done을 추론한다.

    step code + images + state → action code chain
  5. 05

    언어를 보지 않는 actor 실행

    99.4M actor는 현재/미래 action code와 영상·상태를 조건으로 flow matching 기반 행동 chunk를 생성한다. 부록은 비전 인코더 상단 일부의 actor용 미세조정 사본도 집계한다.

    action code + observation → motor actions
  6. 06

    완료 토큰 후 다음 지시 단계로 전환

    현재 동작이 done으로 끝나면 다음 step code를 실행한다. 2-step 실험은 단계 사이 scripted home reset을 수행하며 첫 단계의 목표를 두 번째 동작에서도 유지해야 최종 성공이다.

    done → next step → both goals held
DEEP DIVE / 02

핵심 설계·학습 신호 해설

목표 코드와 동작 코드의 물리 의미는 다르다

여섯 슬롯 의미 코드는 지시의 대상과 목표를 나타내며 2레벨 32개 모션 코드는 각 시연 구간의 행동 특징을 나타낸다. 같은 숫자 토큰이라도 같은 코드 공간이 아니다.

05 / 비판적 해석

한계와 비판적 검토

본 연구의 모든 로봇 실험은 시뮬레이션으로 실제 로봇 강건성을 보증하지 않는다. LIBERO-Para는 단 10개 canonical 작업의 표현 변형이고 강한 '원지시 최근접 검색' baseline은 실험하지 않았다. 일부 DAgger 학습 상태가 500 episode 표준 평가 초기 상태와 겹치므로 저자가 분리 제시한 비중복 300상태 확인이 중요하다. 두 단계 전환 시 scripted home reset을 사용하며 두 번째 단계에서 첫 단계의 완료 상태를 없애는 경우가 22회다. 17ms/step은 74ms 호출을 다섯 스텝에 나눠 환산한 값이지 단일 호출 응답 17ms가 아니다. 다른 연구의 5-seed 평균과 단일 rollout 값은 엄밀한 동일 비교가 아니다.

RESEARCH LAB / EDITORIAL PROPOSAL

내 연구에 적용한다면?

아래는 논문 저자의 검증 결과가 아니라, 논문에서 출발해 설계한 **후속 실험 제안**입니다.

검증 가설

[편집 제안] 문장 강건성 향상의 상당 부분은 discretization의 의미 동치 고정에서 나오지만 새 목표 조합과 OOD 물체명에선 의미 코드 오류가 급증할 것이다.

구체적 실험 설계

[편집 제안] 초기상태 DAgger-overlap 제거, LIBERO-Para 기존 10과제와 새로운 task object 조합에 seed 5개/문장 여러 실행을 적용한다. 두 단계 상태 유지(서랍 재닫힘 등)를 strict predicate로 검증한다.

비교군·Ablation

[편집 제안] SmolVLA+canonical nearest-neighbor rewrite, same-size continuous slots, MDL vs gripper-event segmentation, semantic-code oracle, frozen actor, no temporal ensemble.

기록할 지표

[편집 제안] semantic-slot accuracy, conditional task SR, 2-step both-goals-hold SR, per-pair failure taxonomy, CI, GPU peak memory, call-level latency.

실패 해석·주의점

[편집 제안] 개발/확인 초기상태가 겹치지 않게 고정하고 실제 모터 안전은 별도 저수준 controller가 관리. 1회 rollout 수치를 다중 seed의 불확실성과 혼동하지 않는다.
