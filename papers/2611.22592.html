Distilling World Action Models for Efficient Bimanual Manipulation via Anchored Path Matching

APM은 적은 생성 단계에서 teacher 경로 밖으로 벗어난 WAM student 상태를 그대로 감독의 출발점으로 쓴다. RoboTwin 2.0의 1/1-step Clean 82.3→84.3%, Random 76.1→77.5%, 4/4-step 평균 89.8→91.4%를 같은 계산 예산과 비교했으며, 2/2-step Random 악화와 실제 로봇의 지연·성공률도 함께 분석했다.

00 / ONE-MINUTE RECAP

핵심을 먼저 읽기

APM의 진짜 단위는 교사 trajectory 상의 예쁜 지점이 아니라, 거친 1–4 step student가 실제로 도달한 '어긋난 상태'다. 동일 출발점에서 teacher가 제시하는 최종 endpoint와 당장 다음 local transition을 함께 가르치되 gradient 충돌 시 endpoint를 우선한다. (§3, Figures 1–2)

⌁ DEEP TECHNICAL REVIEW연구자용 상세 해설

읽는 핵심: 생성 단계를 줄였다는 사실만으로 성공률이 오르는 것은 아니다. Figure 1에서 같은 초기 노이즈로 시작한 4-step 학생과 교사의 경로 분기를 확인하고, Figure 2에서 teacher가 실제 student 도착 상태부터 다시 출발하여 두 target을 만드는 것을 추적한다. 1·2·4 step당 Clean/Random 분리 숫자를 보는 것이 이 연구 평가의 핵심이다.

01 / 문제 정의

연구가 풀려는 문제

영상을 같이 생성하는 World-Action Model을 로봇에 넣으면 미래 영상과 행동을 여러 번 denoise해야 해 제어가 느려진다. 8번 혹은 수십 번의 teacher step을 1–4번으로 압축하면, 큰 한 걸음 때문에 student는 teacher가 거쳤던 경로에서 벗어난다. teacher의 원래 궤적 위 정답만 학습하면 새 상태에서 어떻게 복구할지 모른다. 예컨대 양팔이 천을 잡으려다 위치를 살짝 빗나간 학생 상태에서, 원래 teacher 경로의 다음 프레임만 따라가면 완성 동작과 충돌할 수 있다. 논문은 student-reached state에 맞춘 감독과 두 목표의 gradient 조정 문제를 다룬다.

02 / 핵심 기여

핵심 아이디어

학생이 예측한 중간 상태 z_r을 detach해 새로운 출발점으로 고정한다. 이곳부터 frozen teacher를 짧게 다시 적분하면 (1) 마지막 noise=0 완성 영상+행동 z_0^T와 (2) 첫 비영(非零) 시간 중간 상태 z_s^T를 얻는다. 학생은 같은 z_r에서 endpoint query와 local query를 각각 배우고, modality별 LoRA가 둘을 구분한다. 두 손실의 gradient 내적이 음수면 local 쪽에서 endpoint를 거스르는 성분만 지워 최종 상태의 일관성을 우선한다. 한 학생 checkpoint에서 1/2/4-step 예산을 배포 시 선택할 수 있다. (§3.2–3.4)

DEEP DIVE / 04

기존 연구와 무엇이 다른가?

표준 distillation은 원래 teacher 경로의 유한 구간을 효율적으로 모사하지만 학생이 실제 방문하는 상태 분포를 보정하기 어렵다. AnyStep류의 student rollout 감독과 endpoint supervision을 연결하되, APM은 같은 z_r에서 재시작한 한 teacher continuation의 endpoint 및 intermediate를 공동 감독하고 modality별 gradient 투영으로 양쪽 목적 충돌을 조정한다. 높은 sampling budget의 교사 결과와 단순 수치 비교하기보다 추가학습·추론 예산이 같은 Continued가 실제 새 아이디어의 필요성을 시험한다.

03 / 설계와 학습

방법론 · 아키텍처

Stage I에서는 LingBot-VA teacher를 AnyFlow 형태의 finite-interval distillation으로 학습한다. x_t=(1−t)x_0+tε에서 출발해 teacher-integrated target으로 영상·행동을 동시 예측하는 공유 학생을 만든다. Stage II에서는 Stage I 기반 가중치를 동결하고 적은 수의 modality-routed adapter만 갱신한다. z_r은 실제 student prefix rollout에서 샘플링하며 teacher restart continuation을 같은 z_r부터 실행해 endpoint anchor와 첫 local field target을 확보한다. 목표함수는 기본 distillation, endpoint anchor, local field를 포함하고 각 modality에서 endpoint gradient를 보존하도록 local gradient를 투영한다. 저자는 Stage I 약 4,000 steps, Stage II 5,000 steps, batch 32, 영상/행동 각 손실 가중치 1/0.1, 1·2·4 step 샘플링을 기술한다. 추론에서 teacher 호출은 없다. (원문 §3.1–3.4, §4.1)

DEEP DIVE / 01

모델 구조와 처리 흐름

개념적 처리 순서를 정리한 편집 다이어그램이며 원논문의 그림을 복제한 것은 아닙니다.

  1. 01

    LingBot-VA teacher와 영상·행동 결합 상태 정의

    현재 비디오 관측·로봇 상태·언어를 조건 c로 두고, 미래 비디오 latent와 action latent를 함께 이루는 z를 denoising한다. 영상과 행동은 손실 가중치/샘플링 예산을 각각 가질 수 있다.

    teacher (video,action) flow, context c
  2. 02

    Stage I: 모든 구간을 맞추는 AnyFlow student

    t와 r의 finite interval을 입력받아 teacher가 적분한 상태를 모사한다. 학습용 teacher는 조밀한 전이를 제공하고 student는 더 적은 평가 횟수로 같은 구간을 건너도록 최적화한다. 이때 이후 중간 경로의 오류가 누적되는 위험이 남는다.

    x_t→student F_(t→r)→x_r, teacher-integrated supervision
  3. 03

    Stage II: 실제 학생 궤적에서 z_r 샘플

    학습 데이터 노이즈에서 1·2·4 step 조건으로 student prefix를 진행해 z_r을 얻는다. 그 지점을 stop-gradient로 고정하여 teacher 궤적상의 낯익은 지점이 아닌 student의 방문 분포를 대상으로 삼는다.

    rollout student → detach(z_r)
  4. 04

    하나의 restart teacher로 두 목표 수집

    동일 z_r부터 teacher를 noise 0까지 적분해 완성 목표 y0를 얻는다. 그 과정에서 첫 비영시간 중간 상태 ys도 캐시한다. 새로운 teacher rollout을 별도로 한 번 더 수행하는 설계가 아니다.

    Φ_T(z_r): endpoint + short transition
  5. 05

    비디오/액션 adapter에 두 감독을 병렬 제공

    동결된 Stage I backbone 위의 modality-routed adapter가 endpoint query와 local query를 학습한다. 텍스트와 관측 조건은 유지하고, 비디오/행동 loss를 나눠 각 행동 쪽의 충돌을 구분한다.

    base distill + L_anchor + L_field
  6. 06

    Gradient conflict를 endpoint 우선으로 정리한 후 배포

    한 modality에서 local gradient가 anchor gradient와 반대 방향이면 local gradient의 그 반대 성분만 제거한다. 원래 loss는 유지하되 최종점 예측을 망치지 않게 하고, 추론에서는 1/2/4 step을 선택할 뿐 teacher는 없다.

    g_field⊥(g_anchor) on conflict → 1/2/4-step student
DEEP DIVE / 02

핵심 설계·학습 신호 해설

왜 처음의 teacher endpoint만 사용하면 부족한가

원래 초기 노이즈 x1에서 얻은 teacher 완성 y0는 student가 시간 r에서 도달한 z_r과 조건부 전이 거리가 멀 수 있다. 논문 §3.2의 restart anchor는 teacher를 z_r에서 새로 시작해 현재 오차를 반영한다. Table 2는 Original/Restart anchor를 직접 ablate한다.

읽기 포인트Figure 2(a) 회색 Original anchor와 student-reached Restart anchor 비교

한 위치에서 local과 global target 모두

teacher가 만든 짧은 이동 z_r→z_s만 모사하면 최종 영상/행동의 방향을 잃을 수 있고, endpoint만 학습하면 국소의 움직임이 부자연스러울 수 있다. APM은 두 지도의 출발점을 일치시킨다. local target z_s는 원문상 비영 noise 시점의 첫 중간 단계다.

읽기 포인트§3.2 endpoint와 local fields의 동일 출발 상태·첫 intermediate step

Anchor-priority gradient projection

두 손실 gradient가 같은 modality 내에서 음의 내적을 보일 때 field gradient 중 endpoint gradient의 정반대 방향 성분을 빼고 더한다. endpoint 자체를 지우지 않으므로 완성 상태 정합성을 우선한다. 모든 gradient가 상충하면 field이 항상 유익하다는 의미는 아니다.

05 / 비판적 해석

한계와 비판적 검토

Stage I backbone이 LingBot-VA이고 Stage II 교사도 이 계열이므로 타 WAM이나 장기 지평에서 동일 이득은 검증되지 않았다. Table 1의 발표된 LingBot-VA 25/50과 Flash-WAM 1/1 수치는 현지 Continued와 정확히 같은 하드웨어·평가 근거가 아닌 참고값이 포함된다. 2/2-step Random은 성능이 감소하며, Table 2의 field+projection이 모든 조건에서 최고의 선택도 아니다. 실물은 단일 Astribot S1, PenHolder/FoldTowel 두 작업 및 각 24 trial로 제한된다. teacher 8-step 대비 속도 상승을 1-step undistilled teacher 대비라고 잘못 표현하면 안 된다. 별도 Appendix가 없으므로 그 내용을 만들지 않았다.

RESEARCH LAB / EDITORIAL PROPOSAL

내 연구에 적용한다면?

아래는 논문 저자의 검증 결과가 아니라, 논문에서 출발해 설계한 **후속 실험 제안**입니다.

검증 가설

[편집 제안] endpoint 우선 gradient projection은 student trajectory drift가 큰 low-step에 효과적이며, 적은 drift에서는 local field 감독이 오히려 과한 정규화가 될 수 있다.

구체적 실험 설계

[편집 제안] 같은 LingBot-VA teacher에서 Clean 시연·optimizer steps·LoRA rank·seed 3개를 고정하고 1/2/4/8-step 초기 노이즈와 video/action latents의 teacher 대비 편차를 단계별 기록한다. RoboTwin 50 task×50 episode Clean/Random 외에 조도 및 마찰 축을 분리한다.

비교군·Ablation

[편집 제안] Stage I only, Continued, Original anchor, Restart anchor only, Restart+field without projection, Full APM, video-only/action-only gradient projection; 모두 동일 Stage II 5k steps 및 실행 budget.

기록할 지표

[편집 제안] strict success와 Wilson CI, episode-level failure phase, drift norm/endpoint error, PSNR·LPIPS, 추론 p50/p95 latency, teacher continuation 추가 학습 FLOPs, robot 안전 중단 횟수.

실패 해석·주의점

[편집 제안] teacher target 자체가 접촉이나 지각을 잘못 예측하면 restart anchor가 오류를 강화할 수 있다. 형평성 확보를 위해 비디오 샘플 수와 action denoise steps, batch/seed까지 공개한다.
