InteractVLA: Turning VLAs into Interactive Tools for Agentic Robotic Manipulation

기존 VLA를 언어로만 재호출하는 대신, 목표 말단 위치·회전·그리퍼 상태로 샘플링 중 행동을 유도하고 생성 궤적을 에이전트에 되돌린다. LIBERO-Plus 온라인 도구 사용 성공률 93.1→98.3%, RoboDojo 18.0→26.0%, soft-time·action feedback ablation과 실물 평가의 점수 단위를 구분했다.

00 / ONE-MINUTE RECAP

핵심을 먼저 읽기

InteractVLA의 기여는 VLA를 재학습해 더 큰 정책으로 만드는 것이 아니라, 동결된 VLA의 행동 생성 중 기하 목표를 주입하고 그 생성 결과를 에이전트가 되읽을 수 있게 하는 것이다. 소수의 위치 제약을 행동 전체에 강요하지 않는 soft-time 정렬이 중요한 설계다. (원문 §2, Figure 2·3)

⌁ DEEP TECHNICAL REVIEW연구자용 상세 해설

핵심 질문: 좋은 VLA가 물체는 제대로 집는데 새로운 목표 위치를 잘못 선택한다면, 언어 명령을 무작정 바꾸지 않고 그 동작 prior를 살려 방향만 바꿀 수 있을까? Figure 2는 목표 정렬의 시점 문제가 무엇인지 보여주고 Figure 3은 에이전트↔정책의 양방향 진단 루프를 시각화한다. 수치는 저자 Table 1·2·6–8의 평가 단위별로만 서술한다.

01 / 문제 정의

연구가 풀려는 문제

로봇에게 '컵을 집어 오른쪽 상자에 놓아'라고 시키는 에이전트가 기존 VLA를 호출했다고 하자. 타깃 물체를 잘못 고른 VLA가 같은 접근 궤적을 반복하면 에이전트의 '다시 해'라는 언어 지시만으로는 손끝 경로를 정교하게 바꾸기 어렵다. 특히 집기에는 접근→접촉→그리퍼 닫기→들기의 순서가 있다. 목표 위치만 모든 시점에 강요하면 물체에 다가가기도 전에 손을 닫는다. 기존 언어 전용 VLA 도구 호출은 고수준 계획을 저수준 기하 제약으로 넘기는 인터페이스가 약하다. §1·Figure 2(a)는 이러한 실패를 문제로 삼는다.

02 / 핵심 기여

핵심 아이디어

에이전트는 장면을 보고 말단장치 목표 G=(3D 위치, 회전, 그리퍼 상태)를 선택하지만, 촘촘한 관절 경로까지 작성하지 않는다. InteractVLA는 flow 기반 정책의 각 denoising 단계에서 임시 완성 행동 chunk를 읽고 'chunk 중 어느 한 시점이 목표에 도달해야 하는가'를 soft하게 선택한 뒤 목표 포즈와의 미분 가능한 오차로 노이즈 상태를 조금 수정한다. 추론 후 생성된 action chunk를 카메라에 투영해 에이전트에 반환하므로, 에이전트는 목표를 변경하거나 국소 제어 오프셋만 수정할 수 있다. 본래 VLA가 학습한 접근·파지 동작 prior를 가능한 한 유지한다. (§2.1–2.3)

DEEP DIVE / 04

기존 연구와 무엇이 다른가?

기존 agentic robotics는 VLA를 '문장을 받아 움직이는 불투명 함수'로 다뤄 실패하면 언어 재호출을 반복한다. InteractVLA는 모델 내부 flow trajectory를 test time에 geometric energy로 조절하고 역방향으로 action/reprojection을 보여준다. 강화학습 재학습이나 일반적인 trajectory optimization과 달리 pretrained VLA 가중치는 고정이다. 다만 목표 생성의 정확도와 카메라 보정이 새로운 시스템 병목이며, 이 연구는 모든 제약조건을 만족시키는 안전한 기하 제어기를 입증한 것은 아니다.

03 / 설계와 학습

방법론 · 아키텍처

§2.1의 test-time guidance는 에이전트가 선택한 목표 위치 p*, 자세 R*, 개폐 상태 w*와 frozen MR-0 flow action expert를 연결한다. 모델의 중간 노이즈 행동 x_t에서 한 단계 clean prediction을 계산하고, command-to-pose mapping을 통해 chunk 내 말단 포즈를 예측한다. 위치/회전/그리퍼 오차를 정규화한 목표 에너지의 미분을 x_t에 가해 생성 방향을 바꾼다. §2.2의 soft-time은 미리 '마지막 프레임에서 목표'라고 정하지 않는다. 시점별 오차 E_h에 시간에 따라 달라지는 softmax 가중치를 주어 도착 시점을 잠재변수로 두며, 후반 denoising에서 가장 적절한 시점을 분명히 한다. 너무 불일치하는 목표에는 confidence threshold를 적용해 조기 거절한다. §2.3에서는 실행 prefix와 남은 suffix, 카메라 reprojection을 에이전트가 검토하고 목표 재선택 혹은 local edit을 한다. 추가 학습 가중치 없이 test-time 조작하되 카메라 보정과 기하 정확도에 의존한다.

DEEP DIVE / 01

모델 구조와 처리 흐름

개념적 처리 순서를 정리한 편집 다이어그램이며 원논문의 그림을 복제한 것은 아닙니다.

  1. 01

    에이전트가 작업과 장면에서 소수 기하 목표 결정

    언어 목표를 임의의 새로운 관절 동작으로 번역하지 않는다. 현재 카메라 관측에서 접근할 공간 위치, 말단 회전, 그리퍼 열림/닫힘을 묶은 G_k를 고른다. 실패한 목표를 다음 호출에서 다른 후보로 교체할 수 있다.

    관측 o_k, 명령 ℓ → 목표 G_k=(p*,R*,w*)
  2. 02

    기존 flow VLA를 동결한 채 행동 생성 시작

    MR-0 정책이 조건부 flow action expert로 짧은 행동 묶음을 점진적으로 생성한다. 인터페이스는 가중치를 미세조정하지 않고 그 중간 상태에서 완성 행동의 임시 예측을 읽는다.

    노이즈 x_t → 1-step clean action estimate m_t
  3. 03

    목표 에너지를 행동 좌표로 역전파

    command-to-pose mapping으로 각 시점의 예상 말단 위치·자세·그리퍼 상태를 복원하고, 위치·회전·개폐 오차를 한 목표 에너지로 합친다. 미분된 gradient로 현재 노이즈 action chunk를 제한적으로 바꾼다. 과격한 perturbation은 제한한다.

    E_h(G_k, TCP_h) → ∂E/∂x_t → guided flow
  4. 04

    Soft-time으로 '언제' 목표에 도달할지 결정

    고정 마지막 시점에만 정렬하면 접근 단계의 동작이 망가지고, 모든 프레임을 목표에 맞추면 손끝이 순간이동하듯 당겨진다. 시점별 오차의 softmax 분포를 노이즈가 정리될수록 날카롭게 해 하나의 적절한 도착 시점을 찾는다.

    softmax_h(−β_t E_h), β_t=t²/(1−t)²
  5. 05

    신뢰도 검사 후 행동 일부 실행

    목표 오차가 너무 크면 초기 guidance 후 C_t<exp(−1) 같은 confidence rule로 거절하고 재계획한다. 유효한 동작에서는 chunk의 실행 prefix만 수행해 물체·접촉 상태를 갱신한다.

    정상 → 실행 prefix / 불일치 → reject
  6. 06

    생성 행동과 reprojection을 보고 타깃 수정

    남은 행동 예측을 보정된 카메라 시점에 투영해 에이전트가 예상 접촉점과 실제 위치 차이를 진단한다. 타깃 자체가 틀리면 G를 수정해 재호출하고, 동작 전체가 맞으면 접근 높이나 그리퍼 열림 시점만 국소 수정한다.

    행동·카메라 잔차 → target revision / local refinement
DEEP DIVE / 02

핵심 설계·학습 신호 해설

Gradient guidance는 저수준 계획 전체를 대체하지 않는다

논문 §2.1은 flow 기반 action expert의 one-step clean estimate에서 각 chunk 시점의 end-effector 추정값을 얻고 differentiable command-to-pose를 통과시킨다. guidance는 에이전트가 만든 단일 목표의 오차를 줄이는 경향을 주되, VLA가 학습한 접근·접촉 패턴에 의존한다. 따라서 명령-기하 대응이 틀리면 멀쩡한 동작 prior를 오히려 휘게 할 수 있다.

읽기 포인트§2.1의 clean estimate, stop-gradient, guidance normalization, correction clipping

Soft-time은 도달 시점을 추론할 뿐 목표 순서를 자동 발견하지 않는다

한 목표에 대해 frame h마다 E_h를 계산하고 softmax를 쓰며 β_t=t²/(1−t)²으로 후반에 더 큰 차이를 준다. 고정 final-step이나 hard-min보다 연속적인 학습 없는 정렬을 만들지만, 여러 과제의 긴 인과 순서를 이 수식 하나로 학습하는 것은 아니다.

Agent의 반대 방향 인터페이스

§2.3에서는 생성된 행동과 그 reprojection을 에이전트가 받는다. '실패' 이진 신호 대신 물체와 손 사이의 기하 불일치와 앞으로의 예상 궤적을 본다. 같은 목표로 매번 재호출하는 것과 새로운 목표를 고르는 것의 차이를 만든다.

05 / 비판적 해석

한계와 비판적 검토

에이전트의 목표 포즈와 카메라-로봇 좌표 보정이 틀리면 guidance가 불합리한 행동을 강화할 수 있다. 논문은 초기 단계 불일치 목표를 조기 거절하는 규칙을 사용하지만 충돌 회피·접촉력 안전을 보증하지 않는다. RoboCasa365 비교 HexaShell은 다른 훈련/기억 프로토콜이며, RSI 비교는 에이전트 모델·탐색 정책이 완전히 통제되지 않는다. Table 7의 soft-time 이득은 실험 내부 ablation이지만 모든 VLA와 물체에 보편적임을 입증하지 않는다. 온라인 RoboDojo Precision 악화와 실물 trial 수의 제한을 함께 보고해야 한다. arXiv HTML에는 독립 Appendix가 없어 존재하지 않는 부록의 하이퍼파라미터를 만들어 쓰지 않았다.
