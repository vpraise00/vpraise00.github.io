# 1. ViDAL — 행동을 미래 장면 변화에 맞춰 표현하기

- 공식 제목: ViDAL: A Visual Dynamics-Grounded Action Latent Space for Vision-Language-Action Models
- arXiv:2610.08150, 최초 공개 2026-10-06. https://arxiv.org/abs/2610.08150
- 근거: §3.1–3.3, §4.1–4.6의 관련 실험, Table 1–4, Appendix A–C. Figure 2·6 캡션 확인, 실제 이미지 보류.

## 연구 문제와 직관

행동 표현은 정책의 출력과 로봇 컨트롤러 사이의 인터페이스다. 원래 관절 궤적이나 말단 움직임을 압축하는 방법은 움직임을 얼마나 잘 복원하는지는 평가할 수 있지만, 동일한 움직임이 물체에 어떤 변화를 일으키는지는 직접 감독하지 않는다. 예를 들어 동일한 전방 이동이 빈 공간에서는 이동에 그치지만 손끝이 컵에 닿은 상황에서는 컵이 밀린다. 이는 설명을 위한 예시이며 논문의 별도 실험 결과가 아니다. ViDAL은 현재 장면을 조건으로 행동의 결과를 예측하도록 표현 학습을 제약한다. 영상 생성 모델 전체를 정책에 결합하거나 추론 시 미래를 계속 생성하는 방법과 달리, 영상 감독을 별도 Action VAE에 집중시키고 정책 학습 단계에서 이를 동결한다.

## 단계별 학습과 추론 (§3, Appendix A/B)

1. 시점 t의 행동 H개와 정렬된 H+1개 영상 프레임을 구성한다. 행동 정규화 후 시간축 convolution과 residual block으로 Gaussian posterior의 평균·분산을 계산한다. Stride로 시간축 길이를 H/4로 줄인다.
2. 재매개변수화로 연속 잠재 토큰을 표본화한다. 대칭적인 시간축 upsampling decoder가 원 행동 chunk를 복원한다. 이 시점의 확률적 z와 downstream 학습의 결정적 평균을 구분해야 한다.
3. 동결 Wan video VAE로 처음 프레임의 공간 토큰과 나머지 미래 잠재 토큰을 만든다. 미래 query는 행동 latent에 cross-attention하여 미래 토큰을 함께 예측한다. 초기 관측 조건은 동일 행동이 서로 다른 장면 결과를 낼 수 있기 때문에 필요하다.
4. 행동 L1 복원, 시간축 DCT 계수 L1, Gaussian KL, 미래 시각 latent L1의 네 손실을 함께 사용한다. 마지막 목표는 stop-gradient로 고정한다. 주파수와 dynamics 가중치는 각각 1, KL은 1e-4. 영상 모델은 동결되어 표현 목표가 움직이지 않는다.
5. VAE를 동결하고 posterior mean을 정규화하여 정책의 행동 감독 목표로 사용한다. OpenVLA-OFT/StarVLA-OFT의 회귀나 π0.5의 flow matching에서 목표 공간을 교체한다. Appendix B는 π0.5 action expert 학습률을 VLM의 10배로 설정한다고 명시한다. 따라서 모든 optimizer 설정까지 완전히 동일하다고 일반화할 수 없다.
6. 실행 시 VLA가 latent를 생성하고 역정규화한 뒤 동결 decoder로 행동을 복구한다. 미래 predictor와 video VAE는 필요하지 않다. Figure 8의 영상 복원은 분석용 별도 경로이며 실제 온라인 계획 또는 안전 검증은 아니다.

## 한계 및 재현 제안

Random 평균 43.1%는 상당한 실패가 남아 있음을 뜻한다. 장기 과제 개선과 영상 감독의 인과 관계는 같은 데이터 및 정책 head의 loss ablation으로 부분적으로 뒷받침되나, 별도 세계모델이 실행 중 계획을 세운다는 증거는 없다. 실물 과제당 10회는 표본이 작다. 1) 동일 원천 시연과 동일 optimizer, 동일 VLM 및 expert 학습률로 raw/vanilla VAE/DCT/dynamics/전체를 3개 이상 seed에서 비교. 2) 압축과 dynamics 효과를 분리하기 위해 동일 토큰 수의 VAE를 사용. 3) 현재 시각 조건 shuffle, 미래 목표 shuffle을 음성 대조군으로 추가하여 동역학 감독과 단순 regularization 구분. 4) Clean/Random뿐 아니라 접촉·미접촉, 미학습 객체, 카메라 변경으로 성능 분해. 5) end-to-end 지연, decoder 오차 및 주파수별 오차, 100회 평가의 신뢰구간까지 보고. 6) 로봇별 VAE 학습 비용과 한 로봇에서 다른 로봇으로의 frozen transfer를 따로 평가한다.

# 2. WorldContact — 변형 물체의 접촉을 직접 모델링하는 데이터 생성용 세계모델

- 공식 제목: WorldContact: A Contact-Centric World Model for Scalable Robot Learning
- arXiv:2609.19600, 최초 공개 2026-09-17. https://arxiv.org/abs/2609.19600
- 근거: §III–V, Table I/II, 부록 WorldContact Specification, WorldContact Training Details, Policy Fine-Tuning Details. Figure 2·4·5·6 캡션 확인. 실제 이미지 보류.

## 문제와 기존 연구 한계

천 소재의 가방은 접촉이 생길 때마다 모양과 힘 전달 경로가 변한다. 작은 시간 간격으로 접촉을 해석하는 수치 시뮬레이터는 안정적이지만 데이터 생산 비용이 높다. 영상 예측만으로는 실제 격자나 표면의 관통 여부를 직접 확인하기 어렵다. WorldContact는 WorldParticle의 입자 기반 구조를 계승해 정점 위치와 속도를 예측하는 신경 시뮬레이터다. 예를 들어 손잡이를 들어 올리면 손잡이와 몸체가 서로 떨어져 있더라도 소재 연결 때문에 몸체도 따라 움직이고, 탁자와의 접촉은 따로 해제된다. 이러한 관계를 단일 거리 기반 이웃만으로 다루면 소재 연결과 외부 접촉을 혼동하기 쉽다. 이는 직관적 예시이지 새로운 실험은 아니다.

## 단계별 방법론

1. SimWeaver 기반 시뮬레이터에서 실제 관측으로 보정한 물성·디지털 자산을 사용한다. 가방 20,274 정점, 그리퍼 1,114점, 탁자 16,900점으로 표현한다. 물리 실패, 자기 교차, 비정상 부착, 시야 이탈 등을 걸러낸 궤적만 학습한다.
2. 예측할 객체의 현재 위치·속도·속성·위상과 외부에서 지정된 로봇/환경 기하를 분리한다. 잡고 있는 강체는 prescribed 상태, 놓아서 운동이 자유로운 강체는 예측 상태에 포함할 수 있다.
3. 네 이웃을 별개로 처리한다. 공간 접촉은 유클리드 인접 표면, 위상 접촉은 rest-state UV 연결, 제어 접촉은 로봇/잡은 도구, 환경 접촉은 지지면 등이다. Compact-support learned kernel로 각 이웃 정보를 집계해 정점 토큰을 만든다.
4. 계층 인코더의 self-attention과 bipartite merging으로 global token을 만든다. 원래 정점 token은 보존되어 decoder의 query가 되고, global self-attention 후 cross-attention으로 전역 변형 맥락을 가져온다. 정점별 MLP가 위치·속도 보정량 6개를 출력한다. 부록 기준 width 192, encoder/decoder 각 3층, 8 heads, 약 2M parameters.
5. 원 시뮬레이터 0.002초와 달리 0.04초 간격의 변화를 직접 예측한다. 5-step rollout에서 자신의 예측을 다음 입력으로 사용하여 모든 단계 위치·속도 오차의 gradient를 전달한다. 후속 학습에서 4회 Laplacian smoothing(0.35), 32회 edge constraint로 원래 edge 길이의 0.9~1.1배로 제한한다. 보정 위치 차분으로 속도를 다시 구한다. 8 H100, 93,240 base step과 31,080 projection step.
6. 추론에서 초기 상태와 prescribed control의 시퀀스를 입력하여 자기회귀로 상태를 생성한다. 두 카메라 RGB로 렌더링하고 해당 제어 명령과 짝지어 π0.5를 full fine-tuning한다. 부록 기준 30,000 step, 50-step action chunk. 실제 로봇 실행 시 세계모델은 데이터 생성에 사용됐을 뿐 정책이 온라인으로 물리 상태를 추정한다는 의미는 아니다.

## 한계 및 재현

10배는 상태 rollout에 한정되고 여전히 실제 시간보다 느리다. 물성 파라미터가 객체별로 고정되며 보정된 특정 가방 중심 평가이므로 다양한 재질·물체의 일반화를 보장하지 않는다. 65→95%는 단일 작업, 20회 평가 및 데이터 수 차이를 포함한다. 다음 실험으로 25/50/100/150개에서 동일 데이터 수의 수치 시뮬레이터, 신경 시뮬레이터, 단순 재사용을 비교하고 데이터 생성·필터링·렌더링 시간까지 기록한다. 4가지 접촉을 하나씩 제거하고 projection on/off를 교차 비교하며 MSE, 관통 면적, 파지 유지 시간, 5/25/50-step 오류를 기록한다. 미학습 마찰·강성·가방 기하 split을 만들어 성능 저하를 보고한다. 실제 로봇에서는 동일 reset 분포로 최소 100회 블라인드 성공 평가와 안전 제한을 적용한다.

## 연구 질문

사람이 여러 장면에서 반복하는 유사 조작을 모두 새로 시연해야 하는가? 컵의 위치가 바뀌어도 컵에 접근하고 잡는 상대 궤적은 크게 다르지 않을 수 있다. 그러나 컵을 커피 기계 아래에 놓을 때의 기준 좌표는 컵이 아니라 기계로 바뀐다. 절대 궤적 replay는 이 전환을 처리하기 어렵고 단순 영상 증강은 새 물리적 상호작용을 생성하지 않는다. MimicGen은 하위 작업별로 기준 객체를 정하고 궤적을 새 장면에서 실행한다. 정책을 직접 설계하는 것이 아닌 모방학습에 공급할 데이터를 만든다는 점이 핵심이다.

## 단계별 데이터 생성 및 정책 학습

1. 소수의 사람 시연과 객체 중심 하위 작업의 순서를 준비한다. Delta end-effector pose와 gripper 명령을 가정한다. 하위 작업 종료 metric을 사용하여 시연을 연속 segment로 나눈다.
2. 목표 장면의 초기 상태를 reset distribution에서 표본화한다. 하위 작업마다 관련 원천 segment를 무작위 또는 객체 pose 기반으로 선택한다. 원래 관측된 EEF 궤적과 컨트롤러가 명령받은 target pose를 혼동하지 않는다.
3. 원천 객체와 새 객체의 pose로 target pose를 변환하여 객체 기준 상대 pose를 유지한다. 학회 PDF §4.2의 표기에서 새 world target = 새 객체 world pose × 원 객체 world pose의 역행렬 × 원 world target. 이는 좌표 변환이며 새로운 충돌 회피 경로를 학습하는 절차가 아니다. arXiv의 추출 텍스트에서 행렬 순서가 학회 PDF와 다르게 나타나므로 최종 삽입 전 원본 수식 이미지 확인 필요.
4. 현재 EEF와 변환 segment 첫 target을 연결하는 interpolation을 삽입한다. 변환 목표에서 delta pose를 재계산해 원천 gripper 명령과 함께 실행한다. 작업의 모든 segment를 끝낸 후 성공한 실행의 새 관측과 명령만 데이터에 채택한다. 실패는 데이터 효율 분석을 위한 시도 횟수에 포함해야 한다.
5. 생성 데이터로 robomimic BC-RNN을 학습한다. 이미지 정책은 전방 및 손목 RGB, EEF pose와 그리퍼 상태를 입력으로 사용하며 low-dim 조건은 객체의 GT pose를 추가한다. 일반 simulation 이미지 84×84, 실물 120×160, 이미지 shift augmentation 최대 10%.
6. 정책 실행에서는 학습된 BC가 관측에서 행동을 내며, 데이터 생성기의 객체 pose 관측 가정은 정책 배포에 필요한 GT pose와 구분된다. 따라서 생성에는 시뮬레이터나 pose 추정기, 성공 판정기가 필요하되 image BC 실행은 다르다.

## 한계와 재현 제안

정밀하게 정렬된 하위 작업의 순서와 시작 객체 pose가 알려져 있어야 하며, 장애물이 생기거나 소재가 변형되어 상대 좌표만으로 행동을 보존하기 어려운 상황에서는 실패할 수 있다. 실물의 interpolation은 안전을 위해 50 step(25 interpolation+25 fixed)으로 늘렸으나 저자는 관측과 중간 동작의 연관성 부족을 성능 하락의 가능한 원인으로 제시한다. 이를 확정적인 단일 원인으로 해석하지 않는다. 1) Square와 Threading에서 source 1/10/50개 × generated 200/1000/5000개를 고정 seed로 비교한다. 2) 원천 replay, replay+noise, 객체 좌표 변환, 변환+segment recombination을 동일 성공 데이터 수와 동일 총 시도 수 두 기준으로 각각 비교한다. 3) 초기 위치/회전 perturbation 크기와 실제 물체 pose 추정 오차를 변화시키고 실패 원인을 reachability, collision, contact, gripper로 분리한다. 4) generation success, 정책 success, 작업 시간, 사람 개입을 함께 기록한다. 5) checkpoint 선택은 별도 검증 set으로 수행하고 고정 test로 최종 보고하여 최대 test success 선택 편향을 줄인다. 6) 실물 interpolation 변경은 속도·충돌 제한을 유지한 채 비교한다.
